# 秋招面试准备资料库

这是一个以“原始材料 → 知识编译 → 岗位准备 → 面试复盘 → 持续回流”为主线的 Obsidian 知识库。

## 新目录结构

```text
00-系统/       规则、模板、Schema、工作流
10-原始材料/   未整理的面经、JD、课程、截图和转写
20-个人事实/   项目、实习、数据、证据和项目表达
30-通用知识/   跨项目可复用的方法论
40-题库回答/   围绕单个面试问题组织的回答
50-岗位准备/   针对公司与岗位编译出的准备包
60-面试事件/   真实面试和 Mock 面试记录
70-训练评测/   训练、评分、Bad Case 和评测数据
80-索引看板/   自动生成的索引、队列和统计
90-归档/       过期内容和历史版本
```

## 使用方法

新材料统一放入 `10-原始材料/`，不要直接放进项目、题库或岗位目录。

处理流程：

```text
放入原始材料 → 自动识别 → 生成编译产物 → 建立双向链接 → 更新索引 → 复盘回流
```

## 整理原则

1. 原始内容不覆盖，只生成整理稿。
2. 个人事实、通用知识、题库回答和岗位准备互不替代。
3. 同一份原始材料可以产生多个编译产物，但所有产物必须保留来源。
4. 低置信度内容进入待处理队列，不自动污染核心知识。
5. 旧内容先归档，不直接删除。
