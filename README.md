## AI 产品全景：2025 十大类别

> 来源：学点AI产品｜2025 AI应用的十大类别

市面上AI产品的目标基本围绕四大方向：**信息整合、提效、AIGC、社交**。

| 类别 | 核心方向 | 代表形态 |
|------|---------|---------|
| 1. AI助手与对话类 💬 | 对话、问答、多场景交互 | ChatGPT、Claude、Kimi |
| 2. 创意内容生成类 🎨 | 文生图、文生视频等AIGC | Midjourney、Sora、可灵 |
| 3. 生产力与工作流类 🧑‍💻 | AI Coding、AI生成PPT | Cursor、Gamma、Windsurf |
| 4. 行业垂直解决方案类 📃 | 教育、医疗、翻译等专用AI | 作业帮AI、字节AI翻译 |
| 5. 社交与情感陪伴类 💓 | 虚拟互动、情感陪伴 | Character.AI、星野 |
| 6. 图像处理与编辑类 👗 | 图片编辑、滤镜、修复、特效 | Photoshop AI、美图秀秀AI |
| 7. AI内容分发与搜索类 🔍 | 智能问答、深度检索、内容整理 | Perplexity、秘塔AI搜索 |
| 8. 信息聚合与管理类 📈 | 个性化信息推送的数字助手 | 各类AI RSS、AI通知中心 |
| 9. AI营销与商务自动化类 💼 | 商业化、电商提效 | AI投放、AI客服、AI选品 |
| 10. 端侧AI与智能硬件类 👓 | 设备内嵌AI | AI眼镜、AI耳机、AI Phone |

## 双链关系

```
面试题库 ←→ 岗位准备（100+）
    ↓
日常练习 ←→ 02-AIGC策略
```

- 面试题通过双链关联到适用岗位
- 岗位文件夹通过双链引用面试题和相关资料
- 日常练习可双链到具体岗位
