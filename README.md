## 双链关系

```
面试题库 ←→ 岗位准备（100+）
    ↓
日常练习 ←→ 02-AIGC策略
```

- 面试题通过双链关联到适用岗位
- 岗位文件夹通过双链引用面试题和相关资料
- 日常练习可双链到具体岗位
