## 一、核心定义

漏斗的本质是**分解和量化**——把一个业务流程拆成若干子步骤，用相邻环节的转化率/流失率来衡量每一步的健康度，最终定位"卡在哪里"。

面试官考察的不是你背过哪个漏斗模型，而是你能不能：
1. 快速建立一个合理的漏斗框架
2. 说出每一步的**输入量 → 转化率 → 输出量**
3. 在某个指标异常时，**层层下钻**锁定问题



## 二、五大漏斗模型速查

| 模型           | 适用场景        | 核心步骤                   | 面试使用频率 |
| ------------ | ----------- | ---------------------- | ------ |
| **AARRR**    | C 端增长       | 获取 → 激活 → 留存 → 变现 → 推荐 | ★★★★★  |
| **AIDMA**    | 营销 / 内容分发   | 注意 → 兴趣 → 欲望 → 记忆 → 行动 | ★★★    |
| **电商购物漏斗**   | 交易类         | 浏览 → 加购 → 下单 → 支付 → 复购 | ★★★★   |
| **搜索/推荐漏斗**  | AIGC / 推荐系统 | 曝光 → 点击 → 消费 → 互动 → 留存 | ★★★★★  |
| **B2B 获客漏斗** | 商业化         | 认知 → 兴趣 → 评估 → 试用 → 成交 | ★★     |

> 面快手 AIGC 策略，**搜索/推荐漏斗 + AARRR** 使用频率最高。



## 三、快手推荐系统完整漏斗

```
请求池（候选视频集）
  → 召回（粗筛出几百条）
    → 粗排（模型打分，保留几十条）
      → 精排（精细排序，保留十几条）
        → 重排（去重、多样性、策略干预）
          → 曝光
            → 点击/播放
              → 完播
                → 互动（点赞/评论/分享）
                  → 长期留存
```

### 每步可量化的指标

| 环节 | 核心指标 | 典型量级参考 |
|---|---|---|
| 候选池 | 候选量 | ~10 万条 |
| 召回 | 召回率 | 输出 ~500 条 |
| 粗排 | 粗排通过率 | 输出 ~50 条 |
| 精排 | NDCH / AUC | 输出 ~15 条 |
| 重排 | 多样性分数 | 最终展示 ~10 条 |
| 曝光 | 曝光量 | — |
| 点击 | CTR（点击率） | 3%-8% |
| 播放 | 播放率 | 60%-80% |
| 完播 | 完播率 | 30%-50% |
| 互动 | 互动率 | 5%-15% |
| 留存 | 次日/7日留存 | 40%-60% |

## 四、异常定位实战模板

### 模板：完播率下降分析

> **假设：完播率从 40% 下降到 30%**

**Step 1 — 按场景拆分**
- 推荐流量 vs 搜索流量 vs 关注页 → 定位哪个场景下降
- 如果是推荐流量：是首页推荐还是同城？

**Step 2 — 按内容拆分**
- AIGC 内容 vs UGC vs PUGC → 是否某类内容完播率骤降
- 按时长拆分：短视频（<60s）vs 中长视频

**Step 3 — 按用户拆分**
- 新用户 vs 老用户
- 高活跃 vs 低活跃
- 按地区 / 时间段

**Step 4 — 按时间拆分**
- 什么时候开始下降？
- 是否有版本发布 / 策略变更 / 外部事件？

**Step 5 — 形成假设并验证**
- 假设 1：AIGC 内容占比上升拉低了整体完播率 → 拆分 AIGC/UGC 看
- 假设 2：推荐算法调整导致内容-用户匹配变差 → 看 AB 实验组
- 假设 3：某类创作者内容质量下降 → 按创作者维度拆

## 五、细分拆解的四把刀

| 维度 | 示例问题 |
|---|---|
| **时间** | 哪个时段开始异常？周末 vs 工作日？ |
| **空间** | 哪个入口/页面/地区？ |
| **用户群** | 新老用户？活跃度分层？年龄段？ |
| **内容类型** | 图文/视频/AIGC？时长段？品类？ |

> 对比分析才有结论：和目标比、和上月比、和去年同期比、和不同渠道比、和竞品比。

## 六、练习题

### 练习 1（5 分钟限时）
画出**美团外卖**的用户漏斗，每步写 1 个指标 + 1 个优化方向。

### 练习 2（5 分钟限时）
画出**ChatGPT** 的用户漏斗（从访问到付费订阅）。

### 练习 3（10 分钟）
假设快手**搜索流量 CTR 下降 20%**，用漏斗下钻法给出分析思路（至少拆到第 3 层）。

### 练习 4（10 分钟）
为快手 AIGC 视频生成功能设计一个**创作者使用漏斗**：从"发现功能"到"持续使用"的每一步。
