 你说得对，我重新聚焦到 **AIGC（AI生成内容）推荐** 这个特定场景。AIGC 推荐和传统 UGC/PGC 推荐有本质区别，核心矛盾是：**内容生产端是 AI，内容消费端是人，中间还有质量审核、创意评估等新环节**。


下面我从 AIGC 视角重新拆解这个漏斗，告诉你每一层有什么**独有的策略问题**。

---

## AIGC 推荐的完整漏斗（与传统推荐的差异版）

```
AIGC 内容生成（Prompt → 视频/图文）
  ↓
【入库前质量评估】（AIGC独有：幻觉检测、画质评分、AI标识校验）
  ↓
请求池（候选AIGC内容集，带质量标签）
  ↓
召回（粗筛出几百条，需感知"AIGC身份"）
  ↓
粗排（模型打分，保留几十条，AIGC内容有冷启动特征补齐）
  ↓
精排（精细排序，保留十几条，多目标：播放+互动+质量分）
  ↓
重排（去重、多样性、AIGC混排策略、业务干预）
  ↓
曝光（带"AI生成"标识，影响用户点击率）
  ↓
点击/播放 → 完播 → 互动 → 长期留存
  ↓
数据回流（AIGC内容的行为数据反哺质量模型）
```



## 一、AIGC 独有的前置环节：入库前质量评估

这是传统 UGC 没有的，AIGC 内容在**进入推荐池之前**必须先过几道关：

### 1. 质量+安全打分（Pre-filter）

字节跳动的实践是：AI内容上传时，进行 **质量+兴趣+安全** 三级打分 。

| 评估维度       | 检测内容                | 策略PM关注点                             |
| ---------- | ------------------- | ----------------------------------- |
| **幻觉检测**   | AI生成的内容是否有事实错误、逻辑矛盾 | 比如AI生成的"历史科普"视频，是否把朝代搞错？这需要接入事实核查模型 |
| **画质评估**   | 画面是否模糊、畸变、肢体崩坏、闪烁   | 抖音明确把"画质低质"列为限流雷区                   |
| **内容安全**   | 是否涉黄、涉暴、敏感政治        | 传统审核+AI生成特有的"深度伪造"风险                |
| **AI标识校验** | 是否按规定标注"AI生成内容"     | 抖音2026年新规：未标识直接限流、下架                |
| **原创度评估**  | 是否直接套用他人Prompt、批量换皮 | 防止"模板化重复生成"导致同质化                    |

**策略PM的核心工作：**
- 制定**质量分阈值**：多少分以上的AIGC内容才能进入推荐池？
- 设计**分层准入规则**：高质量AIGC（如专业AI短剧）直接进入主池，低质量（如简单AI换脸）进次级池或限制分发
- **AI标识的展示策略**：标识放在哪里？多大？是否影响点击率？



## 二、请求池：AIGC 内容的"隔离"与"融合"策略

传统推荐只有一个内容池，但AIGC场景需要考虑：
### 1. 池子设计策略

| 池子类型 | 内容 | 策略考量 |
|----------|------|----------|
| **AIGC专属池** | 纯AI生成内容 | 便于单独监控AIGC内容生态健康度，但容易形成"信息茧房" |
| **混合池** | AIGC + UGC + PGC 混在一起 | 用户体验更自然，但需要AIGC内容有足够竞争力 |
| **分级池** | 按质量分分层（S/A/B/C级） | S级AIGC与头部UGC竞争，C级限制曝光 |

**快手/抖音的实践：** 目前两家都在大力扶持AIGC，但策略不同：
- **快手**：走"**广激励"路线，联合导演做"中国AIGC导演共创计划"，强调内容品质** 
- **抖音**：走"精品化"路线，单部AI短剧最高投资500万，流量保底1亿曝光 

**策略PM要决策：** AIGC内容在推荐池中的占比上限是多少？是否对某些类目（如AI短剧）单独配额？



## 三、召回层：AIGC 的冷启动与特征补齐

AIGC 内容最大的痛点：**没有历史行为数据，怎么召回？**

### 1. 冷启动特征补齐（Cold Start Feature Completion）

字节跳动的解法：使用 **语义+标题+封面图生成行为特征embedding**，替代缺失的历史数据 。

具体做法：
- **文本侧**：用LLM提取AIGC内容的标题、标签、剧情摘要，生成语义向量
- **视觉侧**：用多模态模型（如CLIP）提取封面图、关键帧的视觉特征
- **Prompt侧**：把生成用的Prompt也作为特征（比如"赛博朋克风格+武侠剧情"）

```
传统UGC召回：用户历史行为 → 协同过滤 → 相似内容
AIGC召回：    内容语义向量 + 视觉向量 + Prompt特征 → 内容相似度匹配
```

### 2. AIGC 专属召回路

| 召回路            | 原理                          | 举例                            |
| -------------- | --------------------------- | ----------------------------- |
| **Prompt相似召回** | 找Prompt相似的其他AIGC内容          | 用户喜欢"古风+AI绘画"，召回同Prompt风格的新内容 |
| **风格标签召回**     | 基于AI生成的风格标签（如"暗黑氛围感""治愈唯美"） | 抖音强调AIGC要建立"固定风格"标签           |
| **质量分召回**      | 只召回高质量AIGC（如质量分>80）         | 避免低质AI内容污染用户体验                |
| **作者召回**       | 关注某个AI创作者，召回其新作品            | 类似UGC的关注召回                    |

### 3. 快手冷启动模型实践

快手针对冷启动内容（包括AIGC），采用了 **Beta分布预估PCTR** 的方法，替代传统的点估计 。

**核心思想：** 新内容早期CTR预估不准，与其给一个确定值，不如给一个**概率分布**（期望+方差），在探索和利用之间做平衡。实践结果显示：0vv内容有效透出率增长22% 。

**策略PM的关注点：**
- AIGC内容的**保底曝光通道**：新AIGC内容至少保证多少曝光？
- **探索vs利用的平衡**：给AIGC多少流量做"实验"？太多伤害用户体验，太少拿不到数据
- **与UGC的召回竞争**：AIGC召回路是否抢占了UGC的流量？怎么评估？

## 四、粗排/精排层：AIGC 的多目标排序

AIGC 内容的排序目标比传统内容更复杂，因为**质量分本身就是一个重要目标**。

### 1. 多目标公式（AIGC版）

```
RankScore = a×P(播放) + b×P(点赞) + c×P(评论) + d×时长 
            + e×质量分 + f×原创度分 + g×AI标识合规分
```

**新增目标：**
- **质量分**：入库前评估的画质、内容质量、幻觉风险等
- **原创度分**：是否原创Prompt、是否有二次创作价值
- **AI标识合规分**：是否正确标注AI生成（不合规直接降权）

### 2. AIGC 特征工程（策略PM主战场）

| 特征类型          | AIGC特有特征                         | 作用           |
| ------------- | -------------------------------- | ------------ |
| **生成侧特征**     | 使用的AI模型（可灵/即梦/SD）、生成参数、Prompt复杂度 | 判断内容制作投入度    |
| **质量侧特征**     | 幻觉检测分数、画质分、帧间一致性                 | 过滤低质AI内容     |
| **风格特征**      | AI生成的视觉风格标签（如"赛博朋克""水墨风"）        | 匹配用户审美偏好     |
| **作者特征**      | 是否为认证AIGC创作者、历史AIGC作品表现          | 识别优质AI创作者    |
| **用户-AIGC交互** | 用户对AIGC内容的点击率vs UGC点击率           | 判断用户是否接受AI内容 |



## 五、重排层：AIGC 的混排与多样性

这是AIGC推荐**最考验策略PM功力**的地方。

### 1. AIGC 混排策略

用户刷信息流时，AIGC内容和自然内容怎么穿插？

| 策略         | 说明                     | 风险                |
| ---------- | ---------------------- | ----------------- |
| **定坑策略**   | 每N个自然内容插1个AIGC内容       | 用户体验可预期，但AIGC曝光受限 |
| **质量混排**   | AIGC质量分够高才插入，与自然内容公平竞争 | 低质AIGC完全没机会，生态起不来 |
| **用户偏好混排** | 对AIGC接受度高的用户多推，接受度低的少推 | 需要精准识别"AI内容偏好"    |
| **业务强插**   | 平台扶持期强制给AIGC流量         | 短期冲量，长期可能伤害用户体验   |

**抖音/快手的实践：** 两家都在用**流量扶持+分账激励**的方式强推AIGC短剧，但策略侧重不同：
- 抖音：单部作品流量保底3000万-1亿曝光，重点作品投资500万 
- 快手：分梯度累计分账，每千次有效播放最高25元，获奖名额500+ 

### 2. AIGC 多样性策略

AIGC 内容特别容易**同质化**（大家用同样的模型、同样的Prompt模板），重排层需要：

- **风格打散**：不能连续3个都是"赛博朋克"风格
- **模型打散**：避免连续出现可灵/即梦/SD生成的内容
- **题材打散**：AI短剧、AI动画、AI真人演绎间隔出现
- **作者打散**：防止同一个AI创作者霸屏

### 3. 业务策略干预（重排层）

| 干预类型 | 场景 | 策略PM工作 |
|----------|------|------------|
| **流量扶持** | 新AIGC创作者、AIGC短剧大赛作品 | 制定扶持配额、评估ROI |
| **降权打压** | 低质AI内容、未标识AI内容、批量灌水内容 | 制定降权规则、监控误伤率 |
| **活动强插** | AIGC创作大赛、品牌合作AI内容 | 定坑位置、频次上限 |
| **付费内容混排** | AI生成的付费短剧/课程 | 与自然内容、广告的混排策略 |



## 六、曝光层：AI标识对点击率的影响

这是AIGC推荐**独有的用户体验问题**。

### 1. AI标识的展示策略

抖音2026年新规要求：所有AIGC内容必须在画面**醒目位置**放置"AI生成内容"标识 。

**策略PM需要实验：**
- 标识**位置**：左上角？右下角？是否遮挡内容？
- 标识**样式**：文字标签？水印？角标？
- 标识**对CTR的影响**：用户看到"AI生成"后，点击率是升是降？

**假设：** 部分用户可能对AI内容有偏见（觉得"不真实"），导致CTR下降；但也有用户专门找AI内容看（觉得"新奇"）。

### 2. 用户教育策略

- 对"AI内容偏好用户"：可以弱化标识，或把标识做成"AI创作"品牌标签
- 对"AI内容排斥用户"：需要更强的标识提醒，或降低AIGC推送频率



## 七、数据回流：AIGC 的闭环优化

AIGC 推荐的数据回流有特殊之处：

### 1. 质量模型迭代

用户行为数据（完播率、互动率）反哺**入库前质量评估模型**：
- 如果某类AIGC内容（如"AI古风舞蹈"）完播率特别高，说明质量评估模型对这类内容打分偏低，需要调整
- 如果某类内容（如"AI生成的虚假新闻"）举报率高，需要加强幻觉检测

### 2. 创作者反馈闭环

AIGC创作者需要知道：
- 我的内容质量分是多少？哪里扣分了？
- 为什么我的AI视频没流量？是质量问题还是分发问题？
- 怎么优化Prompt能获得更多推荐？

**策略PM可以设计创作者后台的"AI内容诊断工具"。**

## 九、AIGC 推荐的特殊挑战（总结）

| 挑战 | 传统推荐 | AIGC推荐 |
|------|----------|----------|
| **内容质量** | 靠用户举报+人工审核 | 需要**前置AI质量评估**（幻觉、画质、原创度） |
| **冷启动** | 新视频靠作者粉丝+热门 | AIGC靠**语义/视觉特征补齐**+Prompt相似度 |
| **同质化** | 搬运、抄袭 | **模型同质化**（大家都用可灵/即梦）、Prompt雷同 |
| **用户信任** | 内容真实性默认成立 | 需要**AI标识**+事实核查，用户可能排斥AI内容 |
| **创作者生态** | 人创作，有情感连接 | AI创作，需要**新的激励体系**（算力积分、Prompt大赛） |
| **合规风险** | 版权、隐私 | 额外增加**深度伪造、AI幻觉、标识合规**风险 |
