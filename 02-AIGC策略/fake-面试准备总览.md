# 快手 AIGC 策略产品面试准备总览

> 核心目标：掌握**漏斗拆解 → 行业预估 → 数值预估**这条完整思考链路，在面试中做到"结论先行 + 结构拆解 + 数字量化"。



## 三大核心能力

| 能力 | 面试考察点 | 详见 |
|---|---|---|
| 漏斗拆解 | 能否把复杂业务流程拆成可量化的子环节，层层下钻定位问题 | [[10-漏斗拆解能力]] |
| 行业预估 | 能否用费米估算对陌生市场快速给出合理数字 | [[13-行业预估能力]] |
| 数值预估 | 能否为策略效果主动拍出具体数字并给出验证逻辑 | [[12-数值预估能力]] |



## 思考链路

```
发现问题
  → 漏斗定位（哪个环节出了问题）
    → 行业预估（天花板和机会有多大）
      → 数值预估（我的策略能带来多少提升）
```

三件事不是孤立技能，而是一套完整的思考链路。

## 面试黄金法则

1. **结论先行**：先抛量化结论，再展开逻辑（讲师原话："面试中需前置抛出关键结论与量化结果"）
2. **5W2H 确保完整**：What / When / Where / Who / Why / How / How much
3. **对比才有结论**：和目标比、和上月比、同比、和竞品比
4. **不回避数字**：模糊回避比估算错误更致命
