# 判断推理模块复盘笔记

---

## 一、图形推理（重点）

### 题目1：方块移动类

**题目特征：** 每列带有图案的方块数量一致（2、1、2、1、2），有明显的移动规律。

**解题规律：**
- 每次移动一格
- **穿墙**（从一侧出去从另一侧出来）
- **边移边转**（逆时针旋转90°）

**考点延伸/加难度方向：**

| 维度 | 基础考法 | 进阶考法 |
|------|----------|----------|
| 移动方式 | 全部穿墙 | 1/3/5列穿墙，2/4列撞墙（或反过来） |
| 移动步数 | 全部移1格 | 1格→2格→1格→2格交替，或1/2/3/4/5递增，甚至每列步数不同 |
| 移动主体 | 每列都移动 | 每次只移部分列（如只移3列或2列） |
| 旋转角度 | 统一逆时针90° | 混合顺/逆时针，或角度变化（45°/90°/180°等） |

> **核心思维：** 做题时不仅要知道规律是什么，还要知道出题人可能怎么变着花样考你。

---

### 题目2：黑白部分数量关系

**题目特征：** 黑色连成一片，白色被黑色分成两部分。

**解题思路：**

1. **从白球角度考虑：**
   - 白色被分成两块 → 考虑两块之间的关系
   - 若是对称图形 → 考虑对称轴
   - 若无对称性 → 考虑两块的**数量差异**（如面积/格子数）

2. **从黑球角度考虑：**
   - 广东喜欢考**一笔画**
   - 需要有意识地往一笔画方向思考
   - 注意：此题一笔画不成立（有的1笔、有的2笔），但思考方向要全面

---

### 题目3：曲线与切点

**题目特征：** 每个图都有明显的曲线和切点。

**解题思路：**
- 遇到**曲线** → 考虑曲线数量
- 遇到**切点** → 优先数切点数量
- 先从大方向数（不分类），直接数切点总数
- 此题切点数：3→2→1，规律立刻出现

> **补充：** 切点还可细分为曲曲切点、曲直切点等分类考点，思考时要全面，但优先从总量入手。

---

### 题目4：九宫格运算类

**题目特征：** 九宫格中每格有图形，涉及叠加/去同存异运算。

**解题关键：**
- **惯性思维是按行**，但行不通时一定要想到**按列**
- 此题：按行尝试 → 第一行能叠加成第三个，第二行不行
- 转换思路按列：外框可以明显看出列的运算关系（如第一列圆+三角→第三列对应外框）
- 运算方式：叠加、去同存异等

**九宫格阅读顺序总结：**
- 按行（最常见）
- 按列（行不通时必须考虑）
- 回字形（外圈一圈）→ 很少考
- S型 → 很少考
- 穷途末路时才考虑非常规路径

**如果按列的外框能凑出来，优先按列考虑。** 某些情况还需在运算中加入旋转步骤（难度更高）。

### 题目5：三视图（基础题）

**解题方法：**
- 先看明显特征排除（如有两个圆→排除不符合的选项）
- 再对比剩余选项的区别（如某处多了一横）
- 从对应视角验证该特征是否存在

> 此题为基础题，无额外难度。

### 题目6（第76题）：截面图/过三点的平面切割

**题目特征：** 看起来复杂，实则与"过三点的平面切割"本质相同。

**解题方法（以ADE斜切为例）：**
1. 第一幅图一定是白色（斜切下来对应白色区域）
2. 到第二行：最右边一个为黑色，内部数灰色总数（如8个已用完）→ 内部全白
3. 到D和E位置：一白一黑
4. 逐步推理画出截面形状

> 此类题考过很多次，整体难度没有增加，只是需要多看几步，耗时稍多。

### 题目9（第79题）：对称方式 + 直角数量

**解题流程：**

1. **先看对称** → 看到有些轴对称、有些中心对称
2. 但数了发现数量不对（4个都是轴对称）
3. **考试经验：** 一般10道图推中，考1道对称正常，考2道较少见 → 大概率这题不是考对称，排除
4. **再看面** → 数面也不对（2/3/4排除了面）
5. **观察突兀之处：** 第三图半圆处多了个直角 → 考虑**直角数量**！

**直角考点总结：**
- 单纯靠观察不一定能发现
- 直角的特征图不像其他考点那么明显
- 需要有敏感性，能从画法中感受出来
- **做题前就要在脑子里装着这个规律**，虽然不常考，但考出来既简单又可能让你看不出来
- 类似的还有**平行线数量**的考点
- 国考喜欢在全黑阴影图中考直角（因为阴影图很难考其他规律）

### 题目10：汉字图推

**题目特征：** 图形都是汉字，但"强行"画了很多曲线。

**解题思路：**
- 本来可以是直线的地方画成了曲线 → 提示考**曲线数量**
- 同时也有明显的直线 → 考虑**直线数量**或曲线与直线的数量关系
- 数一下即可验证规律

> **核心：** 出题人特意强调的特征就是暗示考点方向。

## 二、定义判断

### 题目11：同居式养老

**定义关键词提取：**
- 落脚点：**养老**
- 方式：**同居**（志同道合的人合租式居住）
- 不限于老人和年轻人
- 互相照顾
- 起居/卧室**相对独立**（不是真正的住在一起）

**选项分析：**
| 选项 | 判断 |
|------|------|
| A. 共享客厅+独立卧室 → 符合"相对独立"+"搭伴养老" | ✅ |
| B. 都结婚了 → 不是搭伴 | ❌ |
| C. 年轻人+互相照顾 → 符合 | ✅ |
| D. 去了养老院 → 跟同居式养老无关 | ❌ |

> "志同道合"不必过度纠结，重点在于"养老"+"搭伴"。

### 题目12：离职率计算

**在册人数计算公式：**
- 在册人数 = 月初人数 + 入职人数 = 月末人数 + 离职人数

**关键考点：**

1. **季度/半年离职率不能简单相加再除**，必须用期初人数+该期间总录用人数（或期末+总离职人数）作为分母
2. 例如第一季度：50（期初）+ 58（三个月录用）= 108 为分母
3. D选项：月初月末平均值算在册人数 → 错误（验证：1月(50+18)/2=34 ≠ 53）

> 题目表述中"月出人数"应理解为"期初人数"，概念可能造成误解。

**选项分析：**

### 题目14：担任公司高管限制（又臭又长的法律题）

**粗读要点提取：**
1. 无/限制**民事**行为能力
2. 某些犯罪未满5年（贪污贿赂、破坏经济等跟钱/经济有关的犯罪，需被剥夺政治权利）
3. 破产清算 → 须为**董事/厂长/经理**且有**个人责任**，限期**3年**
4. 违法吊销 → 须为**法定代表人**（范围比董事经理小）且有个人责任，限期**3年**
5. 失信被执行人

**选项分析：**
| 选项 | 关键判断 |
|------|----------|
| A. 3年有期徒刑+安全管理规定犯罪 → 不属于贪污贿赂/经济类犯罪，且未提及剥夺政治权利 → **可以担任** |
| B. 失信执行人 → 满足第5条 → **不可担任** |
| C. 公司被吊销但只是小员工 → 不是法定代表人 → **可以担任** |
| D. 有限责任公司破产+财务人员 → 不是董事/厂长/经理 → **可以担任** |

> **答题策略：** 先粗读提取关键词框架，看到选项后再回头精确对照。

## 三、类比推理

### 题目21：类比 - 组成关系

**类比：** 细胞 : 线粒体 = 复句 : 分句 → **组成关系**

**排除思路：**
- 矿泉水 : 地下水 → 不可能是组成（交叉或包含）
- 春雨 : 暴雨 → 交叉
- 脑 : 心 → 不同东西，不是组成

### 题目22：类比 - 起源地/常识

**题目：** 沙县 : 小吃 = ?

**解题思路：**
- 想到命名方式或起源地
- 看选项不像命名方式 → 考**起源地**
- 小吃的起源地不是沙县，**沙县小吃**的起源地才是沙县

**常识积累：**
- 汴州 = 汴京 = **开封**（北宋都城）
- "只把杭州作汴州"中的汴州即开封
- 曹县 : 马面裙 → 需要常识积累（不确定时不选）

> **规律：** 粉笔模考喜欢在类比中考常识，真题中常识不会那么多。

### 题目34：翻译推理

**翻译规则复习：**
- "除非A否则B" → ¬A → B
- "只有A才B" → B → A
- 否一推一：A→B 等价于 ¬B→¬A

**此题解析：**
- 题干：精细 → 相似（精推相似）
- B选项翻译：详实准确 → 惊喜（与题干不一致）→ ❌
- 只有才 → 反过来翻译：高质量成果 → 高数据+高决策
- D选项：少量低质 → 否定高数 → 推出 ¬高层 或 ¬高决策 → 但已做出高质量决策 → 所以**成果不佳**

### 题目39：真假推理（四人中一假）

**方法：** 找**不能同真**的两个判断

**翻译四人的话：**
| 人 | 内容 |
|----|------|
| 张 | 飞（赵123等奖） |
| 王 | 一（要么一要么二） |
| 丙 | 李一（李是一等奖） |
| 丁 | 赵>王>李 |

**关键：** 丙（李一等奖）和 丁（赵>王>李，即李不是最高）→ **不能同真**  
→ 说明丙和丁中必有一假 → 而题目说只有一个错 → 所以张和王一定为真

**进一步推导：**
- 王要么一要么二
- 假设王是一等奖 → 丙说李一等奖也错，丁说赵>王>李也错 → 两个错，矛盾
- 所以王**只能是二等奖**

## 总结：核心方法论

| 模块 | 核心方法 |
|------|----------|
| **图形推理** | 移动类看方式/步数/主体/旋转；对称看轴数量和方式；九宫格行列都要考虑；曲线→数曲线/切点；直角/平行线要提前装在脑子里 |
| **定义判断** | 先粗读提取关键词框架，看选项后精确对照；关注落脚点；不要过度纠结修饰词 |
| **类比推理** | 多维度考虑（语义/逻辑/语法）；注意二级辨析（必然vs偶然、内外关系等）；常识题积累 |
| **逻辑判断** | 绝对表述→举反例削弱；支持题常见"解释原理"；比较型结论要针对比较关系；翻译推理是基础功；真假题找不能同真的判断 |
