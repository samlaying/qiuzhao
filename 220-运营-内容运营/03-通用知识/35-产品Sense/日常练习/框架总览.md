# 产品Sense 思维框架

## 通用分析流程（任何题都走这四步）

```
Step 1：问题定义 → 这到底是什么问题？谁的痛点？
Step 2：根因拆解 → 为什么会这样？拆到不可拆
Step 3：多方视角 → 各角色怎么想？
Step 4：解决方案 → 按优先级，说清trade-off
```

---

## 题型识别 → 选子框架

| 题型 | 关键词 | 核心矛盾 | 子框架 |
|------|--------|----------|--------|
| 供需类 | 难打车、抢不到、排队、缺货 | 供给不足 vs 需求过剩 | 拆两端+平台 |
| 增长类 | 拉新、留存、活跃、流失 | 用户价值未被满足 | 漏斗+生命周期 |
| 体验类 | 痛点、优化、满意度、抱怨 | 用户预期 vs 实际体验 | 用户旅程+触点 |
| 商业化类 | 变现、定价、付费、转化 | 用户价值 vs 商业价值 | 价值链条+转化 |
| 竞争类 | 竞品、差异化、壁垒、份额 | 自身优势 vs 对手优势 | 竞争三角 |

---

## 子框架详情

### 供需类：拆两端+平台

```
问题：供需不匹配
  ↓
拆解：
  - 需求端：谁在需求？需求量多大？需求的时间/空间分布？
  - 供给端：谁在供给？供给量多大？供给的约束条件？
  - 平台：如何连接两端？效率如何？
  ↓
方案：
  - 刺激供给（补贴、激励、降低门槛）
  - 调控需求（动态定价、引导分流、预约机制）
  - 提升匹配效率（算法优化、拼单、预调度）
```

### 增长类：漏斗+生命周期

```
问题：增长瓶颈
  ↓
拆解：
  - 漏斗：曝光→点击→注册→激活→留存→变现→推荐
  - 生命周期：新手期→成长期→成熟期→衰退期→流失
  - 找到卡点在哪一步
  ↓
方案：
  - 针对卡点优化
  - 提升每一步的转化率
  - 延长用户生命周期
```

### 体验类：用户旅程+触点

```
问题：体验不佳
  ↓
拆解：
  - 用户旅程：发现→了解→使用→反馈→复用
  - 每个触点的预期 vs 实际
  - 找到体验断裂点
  ↓
方案：
  - 修复断裂点
  - 降低使用门槛
  - 提升超出预期的惊喜点
```

### 商业化类：价值链条+转化

```
问题：变现效率低
  ↓
拆解：
  - 价值链条：流量→用户→付费用户→高价值用户
  - 每一层的转化率
  - 用户愿意为什么付费？
  ↓
方案：
  - 提升付费转化率
  - 增加付费场景
  - 提升客单价（但不伤体验）
```

### 竞争类：竞争三角

```
问题：竞争劣势
  ↓
拆解：
  - 用户：用户选择你/竞品的原因是什么？
  - 自身：你的核心优势是什么？护城河在哪？
  - 对手：对手的优势是什么？弱点在哪？
  ↓
方案：
  - 差异化定位
  - 强化自身优势
  - 攻击对手弱点
```
