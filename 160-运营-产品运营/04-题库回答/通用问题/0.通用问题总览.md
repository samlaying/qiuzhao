# 通用问题总览（按面试轮次）

> 跨公司通用的面试题，按"第几轮 / 谁面 / 看什么"分文件夹组织。项目深挖、产品 Case 题不在本目录（见 [[04-产品Sense]] 各专项）。

| 文件夹 | 轮次 | 谁面 | 这一轮看什么 |
|---|---|---|---|
| `1-业务一面/` | 一轮（约30min） | 业务面试官 | 基础匹配度：经历对口、表达有结构 |
| `2-业务二面/` | 二轮（约45-50min） | 业务面试官 | 真实产品能力 + 动机，会刨根问底、必出 Case |
| `3-Leader面/` | 三轮（约30-45min） | 团队 Leader | 潜力、价值观、稳定性 |

---

## 📁 `1-业务一面/`

> 经历对不对口、表达有没有结构、是不是个能正常沟通的人。

| 题目 | 一句话 |
|---|---|
| [[3.自我介绍怎么讲]] | 2-3分钟讲清：我是谁、做过什么、为什么来、凭什么胜任 |
| [[9.产品感受题怎么答]] | 常用产品 / 功能理解题，看能否从用户视角切到产品视角 |
| [[10.怎么拆解一个AI Agent产品]] | 六维判断框架：问题精度/AI必要性/边界/成本商业/护城河/失败模式 |
| [[11.怎么体现学习能力]] | 别说"学得快"——拿"从不懂到独立交付"的闭环当证据 |

## 📁 `2-业务二面/`

> 真实产品能力 + 动机。会刨根问底、必出 Case 题。

| 题目 | 一句话 |
|---|---|
| [[4.为什么想做产品]] | 动机要靠行动证明，不是靠形容词 |
| [[5.为什么来我们公司]] | 有没有做功课、是不是海投碰运气 |
| [[6.平时怎么研究产品]] | 产品 sense 是不是持续输入出来的 |
| [[13.怎么体现数据分析能力]] | 别罗列工具——讲"我用数据做了什么决策、撬动了什么结果" |
| [[2.怎么设计agent 产品]] | ⏳ 待补充（Case 题，也可移至 [[04-产品Sense]]） |

## 📁 `3-Leader面/`

> 潜力、价值观、稳定性——适不适合这个团队。要真诚务实，不要空泛。

| 题目 | 一句话 |
|---|---|
| [[7.职业规划怎么回答]] | 短期扎根 + 中期专业 + 长期方向，且匹配自身 |
| [[8.怎么理解你要去的业务方向]] | 有没有行业判断、是不是真懂业务 |
| [[1.遇到的最大困难]] | 借一个真困难验证解决问题+抗压+成长思维，STAR+反思闭环 |
| [[12.怎么体现抗压能力]] | 高压下还能结构化产出、情绪稳定——讲特质不是诉苦（和「最大困难」区分） |
| [[14.对实习的期待与目标]] | 别说"想学一切"——讲具体、和岗位匹配的期待+怎么主动争取，衔接 [[7.职业规划怎么回答]] |
