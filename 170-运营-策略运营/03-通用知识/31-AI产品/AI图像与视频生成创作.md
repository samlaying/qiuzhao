
## 一、主流模型能力对比与选型建议

### 1. 集梦 5.0
- **优势**：人物质感与美术一致性表现稳定，做人物效果"还OK"
- **特色**：已内置美颜处理（类似PS/美图秀秀的修瑕步骤），省去后期环节
- **适用场景**：需要稳定人物质感的图生图任务
- **画布独有功能**：支持 4K/8K 超清处理（市面上唯一能刷 8K 的平台）

### 2. 香蕉系列（尤其香蕉二）
- **优势**：擅长场景推演与空间合理性，场景设计连贯性好，美术一致性强
- **劣势**：人物皮肤/头发放大后易显瑕疵；放大后真实皮肤质感反而暴露出"故意的瑕疵"；构图审美相对单一（9张图中可能有5张居中构图）
- **适用场景**：场景内部推演、镜头切换生成、环境空间设计
- **实战验证**：浮光第八集画布全部用香蕉制作

### 3. GPT-2
- **优势**：审美最强、构图最灵活、小图质量高且缺陷不明显；对具象描述响应极佳；美术设定、构图设定、色彩定调全面领先
- **劣势**：大图细节仍存局限（头发和皮肤处理有瑕疵），放大后问题暴露
- **适用场景**：九宫格叙事、风格化输出、环境正反打标注图
- **关键发现**：GPT-2 的小图完全没有大图的缺点 → 可通过"小图生成 → 宫格裁剪 → 高清放大"的流程规避其缺陷
- **对抽象概念**：容易偏差；对具象描述（如"钟表调至凌晨6点""杂志做旧"）响应极佳

### 4. CDs 2.0
- **优势**：多角色视频生成中具备强人脸一致性理解力；通过一张正面图即可做出一致性极高的侧脸图（无需三视图）；能通过正脸的光源和阴影分析出具体骨相
- **适用场景**：视频生图/分镜生成器（用 480P 低成本跑分镜）、多角色一致性控制
- **成本考量**：480P 模式成本较低，适合作为分镜生成工具

### 5. 慢点 7
- 本轮表现比之前强很多，但放大后皮肤仍有一种"抵触感"

### 选型总结

| 需求 | 推荐模型 |
|---|---|
| 稳定人物质感 | 集梦 5.0 |
| 场景推演/空间设计 | 香蕉二 |
| 高审美构图/九宫格叙事 | GPT-2 |
| 多角色视频一致性 | CDs 2.0 |
| 8K 超清放大 | 集梦（即墨画布） |



## 二、图生图核心技巧

### 1. 多图节点融合基础操作
- 一个图片节点可以拉入多张图片，每张图拖入即增加一个子节点
- 可分别指挥每个节点的构图与元素位置
- **基础示例**：三张图融合 → 提示词描述"第一张图的人物主体在画面左侧构图，50mm中焦段拍摄人物背影，人物背着背包，透过背包依稀可见电池道具"

### 2. "镜头切换"指令（高频使用）
- **核心提示词**："镜头切换到 [目标空间]"
- **用途**：
  - 从已知场景切至已知场景（如从飞船切至空间站控制室）
  - 从已知场景切至**未知空间**（依靠模型的美术设定和空间合理性去推演内部结构）
  - 切换到人物背后做反打镜头
- **提示词示例**："切换镜头位置到他的背后反打他的脸"
- **依赖模型能力**：未知空间长什么样，完全依靠模型的美术一致性和空间合理性来解决
- **实战案例**：
  - 从大厅推演出走廊（保持美术体系一致）
  - 加入"半金属照明"提示词 → 整个环境呈现金属冷光感
  - 神秘研究所内部结构 → 与外部场景保持一致的美术体系

### 3. "环境光刷人设图"（原创核心技巧）

**问题**：人设图直接放入新环境 → 光线色温不匹配 → 出现明显"贴图感"，画面廉价

**解决方案**：
1. 将**环境图**和**人设图**拖入同一个图片节点
2. 提示词写："图一的构图不变，根据图二的环境光改变人设图中的光线以及色温色相"
3. 模型会根据环境图的光源感觉，给人设图"刷一遍光"

**效果**：消除割裂感，人物光线自然融入环境

**价值**：省去"把人物做到环境中并调整颜色和透视关系"的巨大时间成本

### 4. 正反打/四角度环境图 + 文字标注（场景一致性核心）

**操作流程**：
1. 有一张环境图
2. 文字节点写需求："我需要这张图的正面和反面（正反打），列出光线布局和小的陈设"
3. 用大语言模型优化提示词
4. 生成带标注的正反打环境图

**GPT-2 的独特优势**：
- 会自动在图上做**文字标注**（标注场景中每个位置/道具是什么）
- 这些标注可用于精准调度人物运动路径和道具交互

**提示词示例**：
> "环境正反打，列出里边的具体道具细节，钟表改成凌晨6点"

**标注的实际用途**：
- 告诉模型"让人物走到椅子上，拿起毛毯，走到唱片机位置放一首歌，再回到落地镜照镜子"
- 因为每个位置都已标注，模型不会走错

### 5. 参考图查找方法
- 推荐网站（视频中提到的网址）：可以上传图片，网站会延展出同风格/同类型的更多参考图
- 找到参考图后直接拖入画布节点使用
- **延展用法**：选择一个类型的参考图可以不断拓展出更多同类图片

### 6. 融图改图补充技巧
- 两张已生成的图各取优点 → 结合生成新图（如"红色黑色战甲交替，胸部改成什么样，黑色感觉用在哪"）
- 融图多次后出现模糊/蒙了一层东西 → 使用画布的**4K 高清化**功能（完全重置图片，非简单修复）

## 三、视频生图与分镜生成实践

### 1. CDs 模型作为低成本分镜生成器
- 使用 CDs 的 480P 模式，成本低
- 只需提供**人物图 + 环境图 + 简单提示词** → 快速产出基础关系图
- **工作流程**：
  1. 写好5个镜头的描述
  2. 用 CDs 480P 跑出分镜视频
  3. 其中部分镜头可用，部分不可用 → 对不可用的镜头进行截帧处理

### 2. "截帧 → 高清化 → 再生成"闭环
- 从视频中截取关键帧（画布上"截取4帧"功能，不花钱但不太清楚）
- 对截帧做**高清化处理**（4K）
- 用高清化后的图继续生成视频
- **价值**：视频本身可能没用，但最后一帧的图片价值可能很高 → 后续镜头的光影可以此为基础

### 3. 截帧后光线重匹配（关键步骤）

**问题**：从一个环境截帧的人物放入新环境 → 光线/色温完全不匹配（颜色不对）

**解决方案**：
- 提示词："调整人物在画面中的光线，所有光源来自于环境中，光球发出微弱的光"
- 即：分析新环境中光的来源，让人物匹配该光源

**效果对比**：修改前后差别非常大，从明显不融合变为自然统一

**方法论**：简单分析环境中光都是哪来的 → 写入提示词 → 一句话搞定

## 四、人物与场景一致性控制策略

### A. 人物一致性

#### 1. 人设图格式选择
- **推荐**：单张正面高清**大头/半身**人设图
- **避免**：全身构图的人设图
- **原因**：模型算力有限 → 计算全身构图时脸部精度下降 → 一致性难以保持
- 正面图的分辨率越高，模型能获取的面部细节越多

#### 2. 人设图遮挡脸部技巧
- **方法**：遮挡脸部，保留发型
- **原因**：防止模型参考到不该参考的脸部细节（如其他角色的脸）
- 工具：美图秀秀等即可完成

#### 3. 多角色同框身高控制
- **方法**：
  1. 制作带**身高数值标注**的合照图（遮住脸，保留发型和身材）
  2. 提示词中写入"参考此图比例""注意两人的身高比例，参考这张图"
- **制作提示词**：将多人人设图拖入同一节点，写"图一身高XX，图二身高XX……帮我列出有身高具体数值的比例图，X个人全都正面站着朝镜头"
- **适用场景**：常出现的角色同框时固定身高和身材比例

#### 4. 算力分配注意事项
- 15秒视频 + 单人单场景 → 一张图怎么复杂都能还原
- 多人 + 场景 + 复杂互动 + 运镜指令 → 算力紧张，需精简人设图
- **关键**：给模型**唯一性的选择**，一致性控制就不会太差
- **注意**：人物换衣服时一定要检查脸有没有变化，变化过大则不可用

#### 5. CDs 2.0 的人脸理解能力
- 通过一张正面图能完全做出一致性极高的侧脸图
- 通过正脸的光源和阴影分析出具体骨相
- **不需要三视图**

### B. 场景一致性

#### 1. GPT-2 生成标注化环境图（革命性简化）
- **以前**：肉眼提取光感 → 提取色调 → 反推提示词 → 再丢给模型（复杂且低效）
- **现在**：一句话搞定

**操作**：
1. 一张环境图 + 文字描述需求
2. "环境正反打，列出具体道具细节"
3. 大语言模型优化需求为具体提示词
4. GPT-2 生成带标注的正反打图

#### 2. 标注图的使用方法
- 利用标注位置/道具 → 指导镜头中人物与环境的互动
- 精准控制人物运动路径
- 桌上放什么杯、钟表调到几点、杂志做旧程度 → 都可指定

#### 3. GPT-2 做环境的优势
- 做环境不像做人那样有大偏差
- 环境质量目前非常好
- 细节出色：皮衣质感、反光、水晶杯、做旧杂志、书柜布局等

## 五、画布实用功能与进阶玩法

### 1. 导演台节点（新功能）
- 新建导演台节点 → 打开后可摆假人/道具
- 支持添加：阵列（多人同时）、道具资产库（桌子、墙等简单资产）
- **使用流程**：
  1. 摆好想要的布局
  2. 摄像头按"确认构图"
  3. 出现构图确定的图
  4. 可找参考图 → 用导演台的机位功能找到类似拍摄位置
  5. 拉新节点 → 进行纹身/人物生成
- **注意**：刚上线一两天，可玩性强，持续更新中

### 2. 宫格裁剪
- 确定宫格大小（如 3×3）
- 自动将图分成多份
- 选择想要的小图 → 单独提取
- **核心价值**：GPT-2 生成的九宫格图，小图质量高且不带大图缺点 → 裁剪出小图 → 再高清放大 → 获得高质量分镜

### 3. 风格转会
- 图片 → 风格转会 → 选择致敬导演级色彩滤镜
- 不同颜色 = 不同情绪引导
- 示例：压抑色（寂静岭风格）、忧郁色、明亮色、黄色滤镜
- **底层逻辑**：色彩影响观众对同一表情/场景的情感解读
- 底图色调会控制后续所有视频的大范围色调

### 4. 4K/8K 高清化
- **4K**：画布上直接可做
- **8K**：仅在即墨画布中可用（集梦平台）
- **关键设置**：细节生成程度务必调至 **1**（开得越高改变越多，5成以上质感开始下降）
- **原理**：高清化是完全重置图片（根据已有设定重新生成），非简单修复
- **适用场景**：融图多次后模糊、截帧不清楚、小图需要放大

### 5. "对抗锐化/去纹理"改图提示词
- 针对已有图片太细碎/过度锐化的情况
- 提示词可修复一定程度的过度处理（但非百发百中）
- 有中文和英文两版提示词
- **最佳方案**：修复只是补救，重新生成仍是首选

## 六、提示词工程与模型驯化逻辑

### 1. 首句固定画风（最重要原则）
- **逻辑**：提示词的第一句和最后一句最关键（适用于图片、视频、大语言模型）
- **画风前缀示例**：
  - 3D CG 真人风格："这是一张真实性的图片"
  - 2D 动画："这是新海诚风格的人设图"
  - 胶片质感：指定胶卷品牌（富士/柯达）

### 2. 反面参考法（GPT-2 高度敏感）
- **结构**："画面应该像 X，而不是像 Y"
- GPT-2 对这种对比句异常敏感
- 可根据不同情况单独使用或自行改写

### 3. 具象 vs 抽象描述
- GPT-2 对**具象描述**响应极佳："钟表调至凌晨6点""杂志做旧"
- 对**抽象概念**容易偏差
- **建议**：越具体越好，越抽象越不靠谱

### 4. GPT-2 驯化网页资源
- 专门制作的网页，包含：
  - 模型的"脾气"（更认什么样的提示词）
  - 通用前缀和后缀模板（可直接复制粘贴）
  - 对抗锐化、去纹理等改图提示词
  - 反面参考法的结构和示例
- **重要**：不要只复制粘贴，要理解逻辑后再使用

### 5. 大语言模型辅助优化提示词
- 即使你只写了一句话的需求 → 让大语言模型帮你优化为更具体的提示词
- 优化后再丢给图片/视频模型

## 七、九宫格叙事 + 小图高清化流程（GPT-2 独有优势）

### 完整工作流
1. **写好故事** → 让大语言模型细化为九宫格的起承转合
2. **GPT-2 生成九宫格图** → 小图质量高、审美在线、无大图缺点
3. **宫格裁剪**（3×3）→ 选出想要的分镜小图
4. **4K/8K 高清化** → 小图放大为高清大图
   - 可在集梦画布做 8K（细节生成程度调至 1）
   - 也可直接做 4K（足够用于视频）

### 关键发现
- GPT-2 的大图有头发和皮肤问题 → 但小图完全没有
- 小图中不保留GPT大图的缺点
- 宫格裁剪后的小图虽小但清晰度可接受 → 高清化后质量到位

### GPT-2 vs 香蕉二（同提示词对比）
- GPT-2：构图多样（三分法、荷兰角剪影、前景遮挡等）、色彩丰富、年代感/服装/造型/环境一致性全面领先
- 香蕉二：构图单一（居中构图过多）、审美理解力差距明显

## 八、摄影基础知识

### 1. 焦段特性

| 焦段 | 特征 | 对应场景 |
|---|---|---|
| 14mm | 广角畸变强，视野极宽 | 大场面、建筑、夸张透视 |
| 28–35mm | 接近手机摄像头（手机出厂设置范围） | 日常记录、环境人像 |
| 85mm | 中长焦，压缩背景，开2-3倍变焦效果 | 人像特写、半身（经典人像焦段） |
| 200mm | 长焦，强烈虚化 | 面部特写、远距离拍摄 |
| 300mm | 超长焦 | 野外拍鸟/野生动物 |

- **同一焦段可拍**：面部特写、半身、全身 → 只是人物和背景关系变化
- **提示词写法**：如"85mm拍摄""200mm拍摄人脸面部特写""F1.8大光圈"
- **光圈效果**：F1.8 大光圈虚化强，F2 稍弱但仍偏长焦质感

### 2. 经典构图法

| 构图法 | 说明 | 叙事作用 |
|---|---|---|
| 三分法 | 将画面分为3×3网格，主体置于交叉点 | 最经典，平衡且自然 |
| 对称构图 | 画面左右/上下对称 | 强迫症友好，营造稳定/庄重感 |
| 引导线 | 利用透视关系的线条引导视线 | 强调纵深感和方向性 |
| 框架式 | 利用前景元素形成"画框" | 增加层次，聚焦主体 |
| 对角线构图 | 主体或线条沿对角线分布 | 增加动态感和张力 |
| 荷兰角 | 画面倾斜 | 营造不安/紧张/戏剧性 |
| 前景剪影/遮挡 | 透过前景物体看主体 | 增加叙事深度和窥探感 |
| 居中构图 | 主体放正中 | 需配合环境对称使用效果最佳 |

### 3. 构图使用建议
- **不要**总是用人物居中正面大头/胸像面对镜头说话（最常见的"AI味"）
- 构图运镜都玩明白后，反过来再用居中构图才能用得特别好
- 居中构图需要环境衬托（如对称的书架、透视关系）才好看

### 4. 电影级布光类型

| 布光类型 | 说明 | 情绪效果 |
|---|---|---|
| 伦勃朗光 | 面部形成三角形光斑 | 戏剧性、神秘感 |
| 蝴蝶光 | 鼻下形成蝴蝶形阴影 | 优雅、美化面部 |
| 其他类型 | 课件中整理了多种经典布光 | 各有对应情绪效果 |

- 每种光在电影中的应用案例、效果名称都有整理
- 文件会打包提供给学员

## 九、风格转换与 2D/3D 转换技巧

### 1. 真人/3D 转 3D 效果差
- 真人转 3D 目前转不过来
- **正确方法**：用 2D 去转 3D → 越平面转过来效果越好
- 2D 转 3D 可以拉出不错的 3D 质感

### 2. GPT-2 vs 香蕉（转 3D 对比）
- GPT-2 对人物身材的理解特别棒
- 香蕉转出的效果"差点意思"

### 3. 胶片质感提示词
- 指定胶卷品牌："富士胶卷的颜色""柯达胶卷"
- 可搭配其他描述如"胶片质感的纹身图"

## 十、关键工作流程总结

### 流程一：人设图 + 环境融合
```
人设图 + 环境图 → 同一节点 → "图一构图不变，光线按图二重绘" → 消除贴图感
```

### 流程二：低成本分镜生产
```
人物图 + 环境图 → CDs 480P 跑视频 → 截帧 → 4K高清化 → 继续生成视频
```

### 流程三：GPT-2 九宫格高质量分镜
```
故事文本 → 大语言模型细化 → GPT-2 生成九宫格 → 宫格裁剪 → 4K/8K高清化 → 分镜素材
```

### 流程四：场景一致性控制
```
一张环境图 → GPT-2 生成正反打标注图 → 标注用于调度人物运动和道具交互
```

### 流程五：截帧光线重匹配
```
视频截帧 → 分析新环境光源 → 提示词"所有光源来自环境中XX" → 人物与环境光影融合
```

### 流程六：多角色身高一致性
```
多人人设图 → 同一节点 → 标注身高数值 → 提示词"参考此图比例" → 固定身高身材
```

## 十一、附录：实操要点速查

### 人设图格式要点
- 正面大头/半身高清图（非全身）
- 算力紧张时遮住脸保留发型
- 多角色合照标注身高数值
- 首句固定画风

### 高清化注意事项
- 集梦 8K：细节生成程度调至 **1**
- 4K 足够用于视频生产
- 高清化 = 完全重置（非简单修复）

### 提示词优先级
- **第一句**：画风/风格锚定（最重要）
- **中间**：具体内容描述
- **最后一句**：也较关键

### 模型选择速查
- 人物质感 → 集梦 5.0
- 场景推演 → 香蕉二
- 审美/构图/九宫格 → GPT-2
- 视频一致性 → CDs 2.0
- 8K 放大 → 集梦（即墨画布）
