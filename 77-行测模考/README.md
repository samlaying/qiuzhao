# 行测模考与复盘

笔试行测的模考刷题、视频复盘和模块笔记。与面试回答评测、AI 评测**物理分开**，互不混放。

> 行测（行政职业能力测验）属于**笔试评测**，不是面试回答评测。面试 mock 打分去 `70-训练评测/71-回答训练/`，AI/Agent 评测方法论去 `74-评测数据/评测准备/`。

## 三大模块

| 模块 | 文件夹 | 覆盖内容 |
|---|---|---|
| 言语理解 | `言语理解/` | 逻辑填空、片段阅读、阅读理解 |
| 判断推理 | `判断推理/` | 图形推理、定义判断、类比、逻辑判断 |
| 数资资料 | `数资资料/` | 数量关系 + 资料分析 |
| 备考指导 | `备考指导/` | 选岗、报考策略等非模块内容 |

每个模块下分两类：
- `模考复盘字幕/`：B 站模考复盘视频的 srt 转录，文件名保留 BV 号与原始描述便于溯源。
- `复盘笔记/`：自己整理的错题和方法论笔记。

## 新内容规则

1. 模考复盘视频转写得到的 srt，按模块放进对应 `模考复盘字幕/`，文件名保留 `BV号_原始描述.ai-zh.srt` 格式。
2. 自己整理的错题、套路、公式笔记放进对应模块 `复盘笔记/`，命名 `模块-主题笔记.md`。
3. 整套模考的横向复盘（跨模块）放模块顶层，不要塞进单个模块。
4. 不属于三大模块的备考内容（选岗、报考、时间规划）放 `备考指导/`。
5. 字幕是原始材料，不覆盖；产出整理稿另存为笔记并保留来源链接。
