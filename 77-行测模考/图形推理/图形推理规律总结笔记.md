
## 一、学习方法论

- **不要罗列枚举规律**（像背字典一样逐条背，效率低且永远背不完）
- **要"织网"**：掌握一个框架体系，让所有规律都在这张网的范围内
- 每年新题会有新变化，但万变不离其宗，几乎跳不出"345"这个圈

## 二、核心框架：345

| 数字 | 含义 | 适用情境 | 层次 |
|:---:|------|---------|:---:|
| **3** | 移、变、叠 | 图形**高度相似**时首选 | — |
| **4** | 称、取、整、闭 | 图形**不相似**，宏观特征 | 宏观 |
| **5** | 面、线、点、角、素 | 图形**不相似**，微观细节 | 微观 |

## 三、规律"3"——移、变、叠（高度相似时首选）

> **判断口诀：拿到题，所有图看起来高度相似 → 优先考虑移变叠**
> 顺序从"相似度高"到"相似度低"：移 → 变 → 叠

### 3.1 移（移动）

**核心感觉：** 一些元素在背景格子里"动来动去"

#### 需掌握两个维度：

**（1）怎么移**

| 方式 | 说明 |
|------|------|
| 横向平移 | 水平方向移动 |
| 竖向平移 | 垂直方向移动 |
| 斜向平移 | 对角线方向移动 |
| 旋转移动 | 沿外圈顺/逆时针转动（如九宫格外圈走一格） |

**（2）移到头发生什么**

| 情况 | 说明 | 备注 |
|------|------|------|
| **循环** | 移到边界后从另一侧出现 | 最常考 |
| **反弹** | 移到边界后反方向弹回 | 最常考 |
| **消失** | 移到边界后元素消失 | 新考法 |

#### 变形方向（"加花"）：
- 九宫格 → 25宫格 → 多边形格子
- 一个球 → 多个球/多个阴影块
- 有背景格子 → 无线条背景，元素自由移动

### 3.2 变（旋转与翻转）

#### 旋转
- **知识点本质：** 顺时针/逆时针转了多少度
- **考法：** 不会直接简单考，而是
  - 把图搞复杂，让你不容易发现考的是旋转
  - 结合其他考点（如对称轴每次顺时针转45°等）

#### 翻转
- **知识点本质：** 上下翻转 / 左右翻转

#### ⚠️ 旋转 vs 翻转的辨别方法（高频考点）

| 方法 | 操作 | 原理 |
|------|------|------|
| **箭头法** | 定位一根线（如最长边），在对应位置画箭头，比较方向 | 箭头方向相同→旋转；方向相反→翻转 |
| **时针法** | 定位两个点（如两个角），画弧线看顺/逆时针 | 时针方向相同→旋转；方向相反→翻转 |


### 3.3 叠（叠加）

**核心感觉：** 枚举——把所有可能的排列组合都列一遍

> 叠加是"3"中的重难点，知识点较多

#### 五种考法：

| 考法 | 说明 | 示例 |
|------|------|------|
| **相加** | 图1 + 图2 = 图3 | 两个图形合并 |
| **相减** | 图1 − 图2 = 图3 | **顺序相关**（B减D ≠ D减B） |
| **去同存异** | 去掉相同部分，保留不同部分 | **顺序无关**（B去同D = D去同B） |
| **去异存同** | 去掉不同部分，保留相同部分 | — |
| **黑白运算** | 独立逻辑体系，有自己的运算规则 | 黑+白≠白+黑（有方向性） |

#### ⚠️ 相减 vs 去同存异 区别（易混淆考点）

| | 相减 | 去同存异 |
|---|:---:|:---:|
| 顺序是否相关 | **是**（B−D ≠ D−B） | **否**（结果一样） |
| 本质 | 减去公共部分，先减的是被减数 | 无论顺序，相同部分都去掉 |

#### 黑白运算独立性：
- 有自己的内在逻辑，不属于上述四种任何一种
- 白+黑 ≠ 黑+白（结果可能不同）
- 结果不一定是"阴影"，可以是点、其他形状等
- 变形方向：换背景、换元素（不一定黑白块）

## 四、规律"4"——称、取、整、闭（宏观类规律）

> **判断口诀：拿到题，图形不相似，找不到相似点 → 宏观考虑称取整闭**

### 4.1 称（对称）⭐高频

> 对称考评极高，十道题可能考三道，务必优先掌握

| 考法 | 说明 | 示例 |
|------|------|------|
| **轴对称** | 沿轴线两侧完全对称 | 等腰三角形 |
| **中心对称** | 旋转180°后与原图重合 | 平行四边形 |
| **轴+中心对称** | 既有对称轴，旋转180°也重合 | 正方形、圆 |
| **不对称** ⚠️ | 既不轴对称，也不中心对称 | **常用于干扰选项** |

#### ⚠️ 不对称的两大陷阱：

**陷阱一：** 古钱币图形（有阴影）
- 看起来像轴对称，但阴影方向不同 → 实际**不对称**

**陷阱二：** 八卦图（半黑半白）
- 看起来像中心对称，但转180°后黑白不重合 → 实际**不对称**

---

### 4.2 取（曲直性）

| 考法 | 说明 |
|------|------|
| **全曲** | 所有线条都是曲线 |
| **全直** | 所有线条都是直线（五角星也是全直） |
| **有曲有直** | 既有曲线又有直线 |

#### 🔑 重要信号：
> **当所有图形都有曲线和直线时** → 大概率考曲直性相关考点
> （如：数曲线/直线数量、曲线直线之间的运算关系等）

---

### 4.3 整（整体与部分 / 部分数）

- **部分数：** 图形被分成几个独立的连通区域
- 常见于**生活化图形**（船、火箭、太阳等）
- 示例：太阳=1部分，河流=3部分

---

### 4.4 闭（开闭性）

| 考法 | 说明 | 示例 |
|------|------|------|
| **全闭** | 线条围成封闭区域 | 圆、三角形 |
| **全开** | 线条完全开放，无封闭区域 | 一条弧线 |
| **半开半闭** ⚠️ | 既有封闭区域又有开放区域 | 一头开口的图形 |

#### ⚠️ 半开半闭的特殊性：
- 既可看作"特殊的封闭图形"，也可看作"特殊的开放图形"
- 需要**单独记忆**，常作为一类独立考法
- 可能考交替规律：全闭→全开→半开半闭→全闭...

---

## 五、规律"5"——面、线、点、角、素（微观类规律）

> **判断口诀：图形不相似，需要看细节 → 微观考虑面线点角素**
> 顺序按考评频率排列

### 5.1 面（封闭区域）

> **核心方法：三关注**——拿到题考面时，只关注三个维度

| 关注点 | 说明 | 考法示例 |
|--------|------|---------|
| **数量** | 面的个数 | 依次递增：2→3→4；或做差、求和 |
| **大小/面积** | 面的相对大小 | 总有一个特别大的面+一个特别小的面；或面积相等/成比例 |
| **形状** | 面的形态 | 三角形面、四边形面、圆形面的数量规律 |

> **面的定义：** 围出来的封闭区域即为一个面


### 5.2 线（线条）⭐重难点

> **核心方法：三关注 + 两考点**

#### 三关注（关注线的哪个方面）：

| 关注点 | 何时考虑 | 考法示例 |
|--------|---------|---------|
| **直线** | 所有图都有线头/都是用线画的简笔画 | 横线数量 = 竖线数量 |
| **曲线** | 所有图都有曲线和直线 | 曲线条数 = 直线条数 × 2 |
| **边框线** ⚠️ | **所有图都有边框，且边框形状不同** | 边框边数递增；边框形状与内部元素的关系 |

#### 🔑 边框线的识别信号：
> 所有图都有边界/边框 + 边框形状不一样 → 考虑边框线相关规律
> （每回考，正确率都很低，务必注意）

#### 两考点：

**（1）笔画数**⭐⭐

**四种必考虑笔画的特征：**

| 特征 | 说明 |
|------|------|
| 日字变形 | 出现类似"日"字的变形图案 |
| 田字变形 | 出现类似"田"字的变形图案 |
| 线头多 | 能看到很多线条的端点/线头 |
| 框多 | 有很多三角形、圆、方框等封闭图形 |

> **口诀升级：** 不要"走投无路一笔画"（太被动），要**主动出击**——看到上述特征立刻考虑笔画

**数笔画的两种方法：**

| 方法 | 操作 | 原理 |
|------|------|------|
| **去框法** ⭐推荐 | 把基础图形上的框全部去掉，剩下几笔就是几笔画 | 在基础图形上加框不影响笔画数 |
| **奇点法** | 找到所有奇点（发出奇数条线的点），奇点数 ÷ 2 = 笔画数 | 数学图论原理 |

**（2）平行线**
- 关注平行线的组数
- ⚠️ 当出现**三根平行线**时，基本不考平行（数量有争议：2组还是3组？两两算不算？）

### 5.3 点

> **关注点：** 交点、切点、拐点

| 类型 | 说明 |
|------|------|
| **交点** | 线与线相交的点 |
| **切点** | 直线与圆/弧相切的点 |
| **拐点** | 线条方向发生转折的点 |

- 考法：数量递增、全图交点数量相同、各类点之间的数量关系等


### 5.4 角

> **最高频考点：直角**

| 关注点 | 优先级 | 说明 |
|--------|:------:|------|
| **直角** | ⭐⭐⭐ | 最高频，先数直角个数 |
| **锐角** | ⭐ | 直角不行再考虑 |
| **钝角** | ⭐ | — |
| **所有角** | ⭐ | 全部角的个数递增等 |

- 角本身不是非常高频的考点，直角又是角里面的重头戏


### 5.5 素（独立元素）

> **识别信号：拿到题，图形很"独立"，各部分不相连 → 大概率考素**

**什么是素：** 独立的图形元素（不与其他部分相连的独立图形）

| 关注点 | 说明 | 考法示例 |
|--------|------|---------|
| **个数** | 元素的数量 | 三角形每次多1个，正方形每次少1个 |
| **种类** | 元素的类型数 | 始终有三角形和正方形两种元素 |
| **运算** | 元素间的数学关系 | 四则运算、换算、比较 |

#### 素的运算详解：

| 运算类型 | 说明 | 示例 |
|----------|------|------|
| **四则** | 加减乘除 | 三角形个数 = 四边形个数 + 1 |
| **换算** | 元素间等价替换 | 1个三角形 = 3个圆，1个圆 = 2个五角星 |
| **比较** ⭐新 | 元素间的大小/重量关系 | 月亮 > 四边形 > 五角星 > 心形 |


## 六、总览图

```
图推规律体系（345）
│
├─ "3" 移变叠 ──── 高度相似时首选
│   ├─ 移（移动）：怎么移？移到头怎么办？
│   ├─ 变（旋转+翻转）：箭头法 / 时针法 辨别
│   └─ 叠（叠加）：相加/相减/去同存异/去异存同/黑白运算
│
├─ "4" 称取整闭 ── 不相似，看宏观
│   ├─ 称（对称）：轴/中心/轴+中心/不对称⚠️
│   ├─ 取（曲直性）：全曲/全直/有曲有直🔑
│   ├─ 整（部分数）：生活化图形数连通区域

│
└─ "5" 面线点角素 ── 不相似，看微观
    ├─ 面（三关注）：数量/大小/形状
    ├─ 线（三关注+两考点）：直线/曲线/边框线 + 笔画⭐/平行
    ├─ 点：交点/切点/拐点
    ├─ 角：直角⭐最高频 → 锐角/钝角/所有角
    └─ 素：个数/种类/运算（四则/换算/比较）
```

## 七、做题策略总结

1. **观察图形相似度**
   - 高度相似 → "3"（移变叠）
   - 不相似 → 看宏观"4"（称取整闭）或微观"5"（面线点角素）

2. **发现规律后的判断**
   - 发现的规律属于345体系内的 → **优先选择**（主流规律）
   - 发现的规律不在345体系内 → **三思！** 除非非常确定，否则大概率是干扰项

3. **各规律识别信号速查**

| 信号 | 考虑方向 |
|------|---------|
| 图形高度相似 | 移变叠 |
| 有对称感/对称轴 | 称（对称） |
| 所有图都有曲线和直线 | 取（曲直性） |
| 生活化图形/分离的块 | 整（部分数）/ 素 |
| 有日字/田字/线头/多框 | 笔画 |
| 所有图都有边框且边框不同 | 边框线 |
| 图形很独立、不相连 | 素 |
| 有阴影的对称图形 | 警惕"不对称"陷阱 |

---

> **一句话总结：** 345就是图推规律的一张网——**相似看3，宏观看4，微观看5**，优先考虑体系内规律，遇到体系外规律三思而后行。
