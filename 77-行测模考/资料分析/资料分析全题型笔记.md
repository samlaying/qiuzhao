
## 一、增长率（考点一，最常考）
### 1. 识别方式
- **关键词**：「增长/减少 + 百分号」→ 增长率
- 同义表述：同比增速、增幅 → 均为增长率
### 2. 基本公式

| 已知条件 | 列式 |
|---------|------|
| 现期、基期 | $\dfrac{现期 - 基期}{基期}$ |
| 增长量、基期 | $\dfrac{增长量}{基期}$ |

- 单纯计算：一般为 $a \div b$ 形式 → **首选直除**
### 题型一：百分点加减法
- **不会单独出题**，一般出现在综合分析选项或需要由百分点反推增长率
- **核心**：已知基期增速为 10%，比上年「高/低了」几个百分点 → 做加减法
- **易错词**：「回落」「收窄」→ 往小的方向算（减掉百分点）
### 题型二：特定时间段内满足增长率条件的年份计数
- **示例**：2016 至 2020 年，工资同比增速高于 10% 的年份有几个？
- **方法**：逐个比较，年份数据对应增速与 10% 做大小判断

### 题型三：增长率大小比较

- **场景**：给柱状图/表格，问某几年中增速最大/最小的是哪一年
- **列式**：$\dfrac{现期 - 基期}{基期}$

**比大小技巧**：

| 情形 | 方法 |
|------|------|
| 现期与基期数值接近 | 重点看**分子（增长量）**，分子大的分数大 |
| 现期与基期差距大（两倍以上） | 直接看**倍数**：$\dfrac{现期}{基期}$，倍数越大增长率越大 |

---

### 题型四：隔年增长率 ⭐

**公式**：

$$r_{隔年} = r_1 + r_2 + r_1 \times r_2$$

> 已知 2017→2018 增长 10%，2018→2019 增长 15%，则 2017→2019 增长率 = 10% + 15% + 10%×15%

**五大注意事项**：

1. **乘积何时可省略**：当两个增长率**绝对值均小于 10%** 时，乘积项可忽略，直接求和选最接近的选项
2. **有正有负别忘符号**：增长率是下降的，该值为**负数**。两个负数的乘积 → 负负得正
3. **时间间隔不一定是 3 年**：环比（月与月之间）也能用；间隔不必相等（公式都一样）
4. **乘积怎么算**：化分数
   - 例：14.5% × 26.1% → 14.5 ≈ 1/7，26.1 ≈ 26 → 26÷7 ≈ 3.7 ≈ **不到 4%**
   - 两率之和 = 40.6%，加上 ≈ 3.7% → 约 **44.3%**
5. **逆向应用**（真题考过一次）
   - 已知 2019→2017 增长 25%，2019→2018 增长 10%，求 2018→2017
   - 设所求为 $r$，则 $r + 10\% + r \times 10\% = 25\%$
   - 估算：$r + 10\% ≈ 25\%$，乘积项是正的（略微超），所以 $r$ 比 15% 略小 → **约 13～14%** → 代入选项
### 题型五：混合（合成）增长率 ⭐

**口诀**：

> 整体增速**介于两部分之间**，**偏向基数较大的一方**

**示例**：A 现期 1000，涨 10%；B 现期 3000，涨 5%；求整体增速。

- 整体增速一定在 **5%～10%** 之间 → 排除不在范围的选项
- B 的现期更大（基数大）→ 整体增速偏向 B 的 5% 方向

**验证方法**：

| 方法 | 步骤 |
|------|------|
| **求正中间** | (10%+5%)÷2 = 7.5%，判断答案在 5%～7.5% 还是 7.5%～10% |
| **代入选项** | 看离哪边更近。如整体 8%：离 10% 差 2 个百分点，离 5% 差 3 个百分点 → 偏向 10%，与基数大的 B 矛盾 → 排除 |
| **十字交叉** | 整体写左边，上下写两部分增长率，交叉做差（大减小）→ 得到的比值 ≈ 基期量之比 ≈ 现期量之比 |

**反向应用**：已知整体 + 其中一部分 → 求另一部分，口诀相同（整体介于两者之间，偏向基数大的）

### 题型六：年均增长率 ⭐（难度最高）

**识别**：问某时间段内平均每年的增长率
#### 比大小
- 时间段相同时 → 直接比总增长率（首尾相关，与中间年份无关）
#### 计算方法（三种）
**方法一：代入整十验证**
- 适用条件：**选项有差距，尤其被整十（5%、10%、15%、20%…）分隔开**
- 步骤：取 10% 代入，让基期逐年乘 1.1，算到最后一年，看与实际末期量的关系
  - 算出来 ≈ 末期量 → 答案就是 10%
  - 算出来 > 末期量 → 答案不到 10% → 选更小的
  - 算出来 < 末期量 → 答案更大 → 代入更大的验证
- **常用记忆**：$1.1^4 ≈ 1.46$，$1.2^4 ≈ 2.07$
- **技巧**：可利用**隔年增长率**分段计算，减少连乘量（2 年一隔）
**方法二：编数法**（原创方法）
- 适用条件：**选项非常接近**（如 8.3%、8.7%、9.1%、9.5%）
- 公众号/微博有详细讲解
**方法三：近似公式**（仅限增长率非常小时）
$$\text{年均增长率} \approx \frac{(末期 - 基期) \div 基期}{n} = \frac{总增长率}{n}$$

- **结果一定比这个值略小**，选最接近且略小的那个
- **前提**：四个选项数值都在 **5% 以内**
- 若选项是 10%、20% 级别 → 误差极大，**不可用**

## 二、基期量（考点二）

### 1. 识别

- 已知现在求过去（同比/环比）
- **看时间**：求同比 → 用同比增长率；求环比 → 用环比增长率

### 2. 公式

$$基期量 = \frac{现期量}{1 + 增长率}$$

- 直除首选
- **注意**：增长率有正有负，该用哪个别搞混

### 特殊情况：增长率很小且为负数

- 如 $3587 \div (1 - 2.2\%)$，直除不方便（除以 0.978）
- **近似处理**：$a \div (1 - r) ≈ a \times (1 + r)$
  - 拆开乘：$3587 + 3587 \times 2.2\%$
  - $3587 \times 2.2\% ≈ 36 \times 2.2 ≈ 72$（取整估算）
  - 结果 ≈ $3587 + 72 = 3659$
- **适用条件**：$|r|$ 在 **5% 以内** 放心用；5%～10% 看选项不贴太近也能用

> 注：若除以 $1 + r$ 的情况，直除本身已经很快，不必近似
### 隔年求基期

- 先求隔年增长率 → 再用 $现期 \div (1 + r_{隔年})$ → 一步直除
### 基期量差（重要）⭐

- **问法**：A 的基期比 B 的基期多/少多少
- **做法**：

| 选项情况 | 策略 |
|---------|------|
| 四个不同数值（都写"多"或都写"少"） | **分别直除求基期，再做差**（最稳） |
| 两个"多"+ 两个"少" | 先看现期差（选项里一般会有）→ 排除一组 → 再判断剩下两个谁大谁小 |

- **判断基期差比现期差大还是小**：需看增长量关系，不太容易直接看出来 → 联考建议**直接求**
- **经验之谈**：如果花 20 秒还判断不出大小关系，就别犹豫，直接除！
### 基期倍数/比重/平均数

$$基期倍数 = \frac{现期A}{现期B} \times \frac{1 + r_B}{1 + r_A}$$

> 记忆口诀：**交叉来记**，$1+r_B$ 写上面（分子），$1+r_A$ 写下面（分母）

**计算策略**：
- 先算前面 $\dfrac{A}{B}$ 的值，再看后面那个乘数
- 后面那个数大于 1 / 小于 1 / 约等于 1 → 结合选项选择
- 选项有差距 → 后面可能不用精确算

**选项非常接近时的特殊方法**：

| 方法 | 说明 |
|------|------|
| 百分点结论猜 | 现期比重与基期比重的差值 < $\|r_A - r_B\|$，利用此结论锁定范围 |
| 拆分近似 | 若 $r_A$ 不大（20% 以内），$\dfrac{1+r_B}{1+r_A} ≈ 1 + r_B - r_A$，拆开乘前面的值 |

> 拆分近似对倍数、平均数同样适用

## 三、增长量（考点三）

### 识别

- 增长/减少 + **具体数值 + 单位**（多少元、多少吨、上升了多少）
- 公式：$增长量 = \dfrac{现期}{1+r} \times r$

### 题型一：增长量计算（化分数法）⭐

**核心方法**：将增长率化成 $\dfrac{1}{n}$ 的形式

$$增长量 = \frac{现期}{n + 1} \quad (\text{增长时})$$

$$减少量 = \frac{现期}{n - 1} \quad (\text{下降时})$$

**示例**：

| 增长率 | 化分数 | 现期 5555 时的增长量 |
|--------|--------|-------------------|
| +10% | 1/10 | $5555 \div 11 ≈ 505$ |
| -10% | 1/10 | $5555 \div 9 ≈ 617$（减少量） |

**不好化的增长率处理**：
- 例 13.5% → 约为 1/7.4，不好直接用 → 老老实实现期÷(1+r) 再×r
- 或者先算基期，再做差：现期 - 基期 = 增长量

**增长率非常小时**（5% 以内）：
- 分母 $(1+r) ≈ 1$，直接 $增长量 ≈ 现期 \times r$

### 题型二：增长量大小比较 ⭐

**口诀**：「一大一小看倍数」

> 现期大且增长率大 → 增长量一定大；现期大且增长率小（或反之）→ 看倍数关系

**常规用法**：四个都是正增长率 → 直接口诀，大胆用

**不可用/慎用的情况**：

| 情况 | 说明 |
|------|------|
| 倍数非常接近 | 口诀误差大，需精确求增长量 |
| 增长率很大（如 100%、200%） | 建议化分数精确求 |
| 正负混合比变化量 | 不要用口诀！老老实实化分数求 |
| 四个都是负数问减少量最大/最小 | 拿掉负号，照样用口诀 |

## 四、比重 / 倍数 / 平均数

> 三者列式形式相同：都是 $a \div b$ 形式 → 一步直除

### 比重

- **识别**：「部分占整体」「A 占 B 的比重」→ $A \div B$
- 已知整体和比重 → 部分 = 整体 × 比重
- 已知部分和比重 → 整体 = 部分 ÷ 比重

### 倍数

- **识别**：「A 是 B 的多少倍」→ $A \div B$
- **注意**：不是所有带「倍」的都是倍数！「高几倍」「多几倍」「增长几倍」→ 都是**增长率**（先减再除）

### 平均数

- **识别**：「每…」「均…」「单位面积产量」「单价」→ 后 ÷ 前
- 口诀：**多少除以几**（"多少"在前为分子，"几"在后为分母）

### 倍数比值的处理

- 选项给的是「几比几」→ 化成小数再直除
- 如 3:5 → 0.6，5:7 → 0.71 → 直除比较

## 五、比重变化 vs 平均数增长率 ⭐⭐（高频易混）

### 快速区分

| 对比项 | 比重变化 | 平均数增长率 |
|--------|---------|-------------|
| **主体** | 「占」→ 比重 | 「平均」「每」→ 平均数 |
| **单位** | **百分点** | **百分号（%）** |
| **本质** | 现期比重 - 基期比重（做差） | 现期平均数对基期平均数的增长率 |

### 比重变化（百分点题）

**判断升降**：
- $r_A > r_B$ → 比重上升
- $r_A < r_B$ → 比重下降

**估算百分点**：
- 比重差值 **< $|r_A - r_B|$**（几乎一定成立）
- 只有一个选项满足 → 直接选

**精确公式**：

$$\text{百分点} = \frac{A_{现}}{B_{现}} \times \frac{r_A - r_B}{1 + r_A}$$

**快捷算法**（选项接近时）：
- $\dfrac{r_A - r_B}{1 + r_A} ≈ r_A - r_B$（当 $r_A$ 不大时）
- 再乘以现期比重即可

**猜的策略**：
- 没时间 → 可猜满足「< |r_A - r_B|」条件中最小的那个
- **风险提示**：做差值很大（百分之几十）而选项都远小于它时，猜小的不一定对 → 建议算一下

### 平均数增长率

$$r_{平均数} = \frac{r_A - r_B}{1 + r_B}$$

- 分子算差值即可，分母 $1+r_B$ 一般不用精确算
  - $r_B$ 为正 → 分母略大于 1 → 答案比分子差值略小
  - $r_B$ 为负 → 分母略小于 1 → 答案比分子差值略大

### 本质推导（为什么公式不同）

| 比重变化 | 平均数增长率 |
|---------|-------------|
| 本质是**做差**：现期比重 - 基期比重 | 本质是**除法**：(现期平均 - 基期平均) ÷ 基期平均 |
| 提出 $\frac{A_{现}}{B_{现}}$ 后，通分得到含大 A、大 B 的公式 | 正好 $\frac{A_{现}}{B_{现}}$ 被约掉，公式中没有大 A、大 B |

### 特殊注意

1. **比重 + 百分号**（出题人不严谨）：主体是比重 → 仍按**做差/百分点**处理
2. **某某率**（利润率、产销率、考核达标率等）：本质是比重 → 都算**百分点变化**
3. **平均数增长量**（几乎不考）：平均数增长/减少 + 具体数值 + 单位 → 精确计算，计算量大

## 六、多个数求和 / 求平均

### 求和

| 情形 | 方法 |
|------|------|
| 数值接近 | 找**基准数**，多退少补 |
| 数值差距大 | **四舍五入取前两位** |
| 精确加减法 | 看**尾数** |

### 求平均

| 方法 | 步骤 |
|------|------|
| 先求和再除 | 先算总和，再 ÷ n |
| 代入选项验证 | 把选项代入，看「比它多的部分」与「比它少的部分」能否大致抵消 |


## 七、易错概念 / 易错表述

### 1. 翻番

$$翻 n 番 = 2^n \text{倍}$$

- 方法：首尾求倍数 → 转化为 $2^n$ → 求 $n$

### 2. 高几倍 / 多几倍 / 增长几倍

$$\text{高/多/增长几倍} = \frac{A - B}{B} = \frac{A}{B} - 1$$

- **本质是求增长率**，先减再除（或除完再减 1）
- **只有「A 是 B 的几倍」才是直接 $A \div B$**

### 3. 超过

$$\text{「超过」} = \text{「大于」}$$

- 「A 超过 B 的 2 倍」→ $A > 2B$ → 即 $A \div B > 2$
- 直接算倍数比大小，不用减 1

### 4. 多百分之几 / 少百分之几

- **本质相同**，都是求增长率
- $A 比 B 少百分之几 = \dfrac{A - B}{B}$，结果为负的百分之几

### 5. 变化幅度（变幅）

- **= 增长率的绝对值**
- 变化量 = 增长量的绝对值

### 6. 常见近义词

| 词语 | 含义 |
|------|------|
| 约 | 大约、近似 |
| 超过 | 大于 |
| 不到 | 小于 |
| 近 | 接近但小于 |


## 八、时间与量级——两大挖坑陷阱

### 陷阱一：时间坑（联考特别爱考）

| 陷阱类型 | 说明 | 正确做法 |
|---------|------|---------|
| **无增速硬推** | 给 2018 年数据，没说「保持增速不变」就问 2019 年 | → **无法推出** |
| **同比/环比搞混** | 给 2019 年 5 月，问 2018 年 5 月，但材料只有环比增速 | → **无法推出**（需要同比） |
| **时间段不完整** | 给前三季度，问全年 | → **无法推出** |
| **时间要圈完整** | 年份后面带月/季度 → 必须一起圈上 | 「2019 年前三季度」不能只看「2019 年」 |
| **给多年数据问特定区间** | 给 2012—2020 年，问「十三五期间」 | 只看 2016—2020 年 |

### 陷阱二：量级坑

**情形一：选项有 10 倍或 100 倍关系**

- 如选项：241 / 24 / 2.4 → 光看首位没用，必须判断量级
- **方法**：看分母比分子多几位
  - 分母多两位 → 当百分号
  - 多三位 → 当千分号
  - 前面除法估商（如 300÷200 ≈ 1.5）→ 合在一起判断

**情形二：选项刚好在 10 倍附近（如 0.8% 和 8%）**

- 首位都是 8 或 9 → 容易误选
- 必须划线判断量级：看清楚到底百分之几还是百分之零点几

**情形三：综合分析用尾数判断后忘看量级**

- 尾数对上了 ≠ 一定对
- 例：「平均每个图书馆坐席」首数是 2 → 可能是 20 多，也可能是 200 多
- **首数/尾数判断后必须再对一次量级**

**情形四：选项给区间（国考常见）**

- 如：A. 不超过 1%　B. 1%～10%
- 首位是 5 → 可能是 0.5%，也可能是 5% → **必须看量级**

## 九、综合分析的阅读理解题（联考特色）

- 四个选项中有些**完全不涉及计算**，而是问「主要原因是什么」「以下哪个推断正确」
- **做法**：
  1. 先跳过拿不准的选项
  2. 把**能算的、能排的**先处理
  3. 能算的里面有对的 → 直接选
  4. 能算的都不对 → 选那个拿不准的
- **本质**：当成**言语理解**去做，判断前后是否有因果关系、是否为主要原因
- 不要把它当纯计算题！
## 附：公式速查表

| 考点 | 公式 |
|------|------|
| 增长率 | $\frac{现期-基期}{基期}$ 或 $\frac{增长量}{基期}$ |
| 基期量 | $\frac{现期}{1+r}$ |
| 增长量 | $\frac{现期}{1+r} \times r = \frac{现期}{n+1}$（$r = \frac{1}{n}$ 时） |
| 隔年增长率 | $r_1 + r_2 + r_1 \times r_2$ |
| 混合增长率 | 介于两者之间，偏向基数大的一方 |
| 年均增长率 | 代入法 / 编数法 / 近似公式（$\frac{总增长率}{n}$，选略小的） |
| 比重（现期） | $\frac{A}{B}$ |
| 比重变化 | $现期比重 - 基期比重 = \frac{A_{现}}{B_{现}} \times \frac{r_A - r_B}{1 + r_A}$ |
| 平均数增长率 | $\frac{r_A - r_B}{1 + r_B}$ |
| 翻 n 番 | $2^n$ 倍 |
| 高/多/增长几倍 | $\frac{A}{B} - 1$（本质是增长率） |
