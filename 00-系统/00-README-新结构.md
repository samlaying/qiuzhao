# 秋招知识库新结构

本仓库按内容生命周期管理：

```text
10 原始材料 → 20 个人事实 / 30 通用知识 → 40 题库回答 → 50 岗位准备 → 60 面试事件 → 70 训练评测 → 80 索引 → 90 归档
```

## 顶层目录职责

| 目录 | 职责 |
|---|---|
| `00-系统` | Schema、模板、工作流和自动化规则 |
| `10-原始材料` | 未整理的录音、面经、JD、文章和截图 |
| `20-个人事实` | 真实项目、经历、数据、证据和项目表达 |
| `30-通用知识` | 跨项目、跨岗位可复用的方法论 |
| `40-题库回答` | 围绕单个面试问题组织的回答 |
| `50-岗位准备` | 针对具体公司和岗位编译出的准备包 |
| `60-面试事件` | 某一次真实面试或 Mock 的过程记录 |
| `70-训练评测` | 评分、Bad Case、训练记录和评测集 |
| `80-索引看板` | 自动生成的导航、队列和统计 |
| `90-归档` | 过期内容、旧版本和结束岗位 |

## 唯一入口

新的原始内容默认只放入 `10-原始材料/`。不要直接放入项目、题库或岗位准备目录。

## 内容边界

- 原始内容不覆盖，只能生成整理稿。
- 个人事实、通用知识、题库回答、岗位准备分别维护。
- 面试复盘属于面试事件和训练评测，不直接改写项目事实。
- 所有自动生成内容必须保留 `source_id`，可以追溯到原文。
