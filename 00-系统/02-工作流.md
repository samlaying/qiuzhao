# 知识库工作流

## 用户操作

用户只需要把新材料放入 `10-原始材料/`，之后运行 `process-inbox`。

## 自动处理流程

```text
识别类型 → 提取实体 → 生成元数据 → 判断目标目录 → 生成编译产物 → 建立双向链接 → 更新索引 → 写入处理日志
```

## 处理分流

| 输入 | 编译产物 |
|---|---|
| 项目资料 | `20-个人事实` |
| 课程/文章 | `30-通用知识` |
| 面经 | `40-题库回答`、`50-岗位准备` |
| JD | `50-岗位准备` |
| 录音/转写 | `60-面试事件`、`70-训练评测` |
| 评分/复盘 | `70-训练评测`，并回写题库候选 |

## 置信度策略

- `>= 0.85`：自动归档并标记 `verified_candidate`
- `0.60–0.84`：自动生成产物，但进入待复核队列
- `< 0.60`：不改变原始位置，只生成分类建议

## 不可自动做的事情

- 覆盖原始正文；
- 删除原始文件；
- 擅自改变项目事实和数字；
- 将推断写成面试官原话；
- 用一份岗位准备内容污染通用知识。
