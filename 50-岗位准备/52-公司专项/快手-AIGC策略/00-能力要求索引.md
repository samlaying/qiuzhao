# 快手 AIGC 策略产品面试准备指南：三大核心能力提升方案


## 一、漏斗拆解能力

### 1.1 什么是"策略 PM 语境下的漏斗"

漏斗的本质是**分解和量化**——把一个业务流程拆成若干子步骤，用相邻环节的转化率/流失率来衡量每一步的健康度，最终定位"卡在哪里" (citation:2)。

直播中讲师原话：

> "你的整个解决方法，漏斗里面你用了什么样的思考逻辑？比如你怎么去理解用户的痛点，这个痛点是可以怎么量化成一个具体的执行策略的。"

### 1.2 面试中最常用的漏斗模型

| 模型 | 适用场景 | 核心步骤 |
|---|---|---|
| **AARRR 海盗漏斗** | C 端产品 / 增长 | 获取 → 激活 → 留存 → 变现 → 推荐 |
| **AIDMA 消费者行为漏斗** | 营销 / 内容分发 | 注意 → 兴趣 → 欲望 → 记忆 → 行动 |
| **电商购物漏斗** | 交易类 | 浏览 → 加购 → 下单 → 支付 → 复购 |
| **搜索/推荐策略漏斗** | AIGC / 推荐系统 | 曝光 → 点击 → 消费 → 互动 → 留存 |
| **B2B 获客漏斗** (citation:1) | 商业化 | 认知 → 兴趣 → 评估 → 试用 → 成交 |

### 1.3 练习方法

**第一步：选一个你熟悉的产品，画出它的完整漏斗。**

以快手短视频推荐为例：

```
请求池（候选视频集）
  → 召回（粗筛出几百条）
    → 粗排（模型打分，保留几十条）
      → 精排（精细排序，保留十几条）
        → 重排（去重、多样性、策略干预）
          → 曝光
            → 点击/播放
              → 完播
                → 互动（点赞/评论/分享）
                  → 长期留存
```

每一步都可以写出：**输入量 → 转化率 → 输出量**。面试时如果能说出"比如召回阶段我们从 10 万候选池召回 500 条，召回率大约 X%，然后粗排后保留 50 条……"，面试官会认为你有真实 sense。

**第二步：人为制造一个"异常"，然后定位问题。**

> 比如："假设完播率从 40% 下降到 30%，我先看是哪个消费场景下降了——是搜索流量还是推荐流量？再往下看，是哪类内容的完播率下降？是新用户还是老用户？是哪个时间段？"

这就是直播里讲师说的"漏斗拆解"——**层层下钻，锁定问题环节**。

**第三步：练习在白纸上 5 分钟画出任何业务的漏斗。**

面试中 Case Study 经常突然抛一个你不熟悉的场景，你需要快速建立漏斗思维。训练方法：

- 随机选一个产品（滴滴打车、美团外卖、B站视频、ChatGPT），计时 5 分钟画漏斗。
- 每个环节至少写出 1 个可量化的指标和 1 个可能的优化方向。

### 1.4 漏斗拆解的进阶技巧

从搜索结果中的数据分析方法论可以补充 (citation:2)：

- **细分拆解是灵魂**：定位到某个环节后，按**时间**（哪个时段）、**空间**（哪个地区/入口）、**用户群**（新老/活跃度）、**内容类型**（图文/视频/AIGC）进一步拆解。
- **对比分析才有结论**：和目标比、和上月比、和去年同期比、和不同渠道比、和竞对比。
- **5W2H 确保完整性**：What（什么指标异常）、When（何时开始）、Where（哪个环节/入口）、Who（哪类用户）、Why（可能原因）、How（怎么解决）、How much（成本和预期收益）(citation:2)。



## 二、行业预估能力

### 2.1 什么是"行业预估"

面试中说的"行业预估"不是让你背研报数据，而是考察：

> **给你一个不太熟悉的行业/市场，你能不能在几分钟内用逻辑框架估算出一个大致合理的数字？**

这就是经典的**费米估算（Fermi Estimation）**，也是咨询公司 Case Interview 的核心能力。

### 2.2 常见面试题型

| 题型     | 示例                               |
| ------ | -------------------------------- |
| 市场规模估算 | "中国 AIGC 内容创作市场规模有多大？"           |
| 竞争格局判断 | "快手在短视频推荐市场大概占多少份额？"             |
| 趋势预判   | "未来 3 年 AIGC 生成内容在短视频中的渗透率会到多少？" |
| 机会评估   | "快手做 AIGC 视频生成，能撬动多大的增量？"        |

### 2.3 万能拆解框架

**TAM-SAM-SOM 三层漏斗：**

```
TAM（Total Addressable Market）：整个市场的天花板
  → 中国短视频用户 × 人均日消费时长 × 内容供给需求
SAM（Serviceable Available Market）：你能服务到的部分
  → TAM × 快手的市场份额 × AIGC 技术可替代的内容比例
SOM（Serviceable Obtainable Market）：你实际能拿到的
  → SAM × 渗透率 × 转化效率
```

### 2.4 练习方法

**方法一：每天做一道费米估算题**

经典练习题：
- 中国每天有多少杯咖啡被喝掉？
- 北京地铁一天的客流量是多少？
- 快手每天有多少条短视频被上传？
- AIGC 生成一张图片的平均成本是多少？

**方法二：建立你的"数字直觉库"**

面试前至少记住以下基础数据（截至 2025 年）：

| 数据点 | 大致数字 |
|---|---|
| 中国人口 | 14 亿 |
| 中国网民 | 约 11 亿 |
| 短视频用户 | 约 10 亿 |
| 快手 DAU | 约 4 亿 |
| 抖音 DAU | 约 7-8 亿 |
| 中国广告市场 | 约 1.2 万亿 |
| 短视频广告占比 | 约 30%+ |
| AIGC 大模型推理成本趋势 | 每年下降 50%+ |

有了这些锚点，你做任何估算都可以"有据可依"。

**方法三：练习"从结论开始"**

直播讲师明确说了：

> "面试中需前置抛出关键结论与量化结果，再展开逻辑。"

所以你的回答结构应该是：

> "我估算快手 AIGC 视频生成的可服务市场大约是 XX 亿。拆解逻辑是……"

先给结论，再给逻辑。不是从头推导到尾。

### 2.5 进阶：结合 AIGC 赛道做行业预估

既然你面的是快手 AIGC 策略产品，建议提前研究：

1. **AIGC 内容的渗透率**：目前短视频中 AIGC 生成内容占比大约是多少？未来趋势？
2. **成本结构**：生成一条 AIGC 视频的 token 成本、推理时间、质量水平 vs 人工创作。
3. **竞品动态**：抖音、B站、小红书在 AIGC 内容方面的策略。
4. **商业化路径**：AIGC 内容如何影响广告效率、内容供给量、创作者生态。

## 三、数值预估能力

### 3.1 什么是"拍数字差距不大"

直播讲师原话：

> "当你有一个很明确的数值预估，拍的差距不是太大的时候，我认为这个人是有 sense 的，就会加分考虑。"

这说的是：在做策略分析或 Case Study 时，你需要**主动给出具体数字**，而不是只说"大概"、"可能"、"应该会提升"。

### 3.2 面试中的典型场景

**场景 A：策略效果预估**

> "你这个策略上线后，预计能提升多少？"

错误回答："应该会有明显提升。"

正确回答："我预估点击率可以从 3.2% 提升到 3.8%，大约提升 0.6pp。逻辑是：当前 AIGC 内容的点击率比 UGC 低约 1pp，主要原因是封面质量不足；通过优化封面生成策略，预计能弥补其中 60% 的差距。"

**场景 B：成本收益分析**

> "做这件事值不值？"

正确回答："假设日均需要调用 AIGC 接口 100 万次，单次成本约 0.01 元，日成本约 1 万元。如果能提升内容消费时长 2%，按 DAU 4 亿、每分钟广告收入 X 元估算，日增量收入约 XX 万，ROI 约 X 倍。"

### 3.3 练习方法

**方法一：建立"业务公式"思维**

每个业务场景都可以写出一个核心公式。例如：

```
短视频平台广告收入 = DAU × 人均消费时长 × 每分钟广告 load × eCPM / 1000

AIGC 内容带来的增量 = 新增内容量 × 内容消费率 × 对留存的边际贡献 × 用户 LTV 提升

策略优化效果 = 受影响用户占比 × 当前基线 × 预期提升比例
```

练习时，随便给一个策略场景，写出公式，填入你拍的数字，看结果是否"说得通"。

**方法二：回溯验证法**

看到一个行业数据后，尝试用底层逻辑反推它是否合理。

> 比如："快手 2024 年广告收入约 600 亿。我来验证一下：DAU 4 亿 × 人均消费 120 分钟 × 每 5 分钟 1 条广告 × eCPM 30 元 / 1000 = 4亿 × 120/5 × 30/1000 ≈ 288 亿……嗯，看起来偏低，说明我的假设可能保守了，或者还有其他广告形式（开屏、信息流以外的）在贡献。"

这种"自我验证"的能力会让你的数字 sense 越来越准。

**方法三：记录真实业务数据**

如果你有任何实习/项目中的真实数据（DAU、转化率、CTR、留存率等），一定要记住。面试时用真实数据举例，比拍脑袋估算更有说服力。

直播讲师也强调了：

> "不要隐瞒数据，真实性比保密更重要。模糊或回避数据，面试官可能质疑造假或没做过。"

### 3.4 快手 AIGC 策略的数值预估练习

试着回答以下问题，每个问题都给出具体数字：

1. 快手每天的视频上传量大约是多少？其中 AIGC 生成的可能占比多少？
2. 如果 AIGC 视频的完播率比 UGC 低 15%，对推荐系统的核心指标（如人均消费时长）影响有多大？
3. 假设要上线一个 AIGC 封面优化策略，覆盖 20% 的新上传视频，预估点击率提升多少？
4. AIGC 生成一条 15 秒视频的成本大约是多少？和 PUGC（专业用户生成内容）的成本对比如何？

## 五、最后一个提醒

直播讲师说的那句话非常关键：

> "面试中的问题有 50%，其实工作中就已经存在。"

你现在被捞起来说明简历已经过关了。接下来的面试，本质上考察的是你**能不能用策略思维解决问题**。漏斗拆解、行业预估、数值预估，这三件事不是孤立的技能，而是一套完整的思考链路：

```
发现问题 → 漏斗定位（哪个环节出了问题）
         → 行业预估（这个问题的天花板和机会有多大）
         → 数值预估（我的策略能带来多少提升）
```

把这条链路跑通，面试就不会差。加油。
