## 使用方式

### 面试题库
- 每道题独立一个文件
- 用双链关联适用岗位：`适用：[[110-产品-策略PM]]、[[210-运营-用户运营]]`
- 同一道题可关联多个岗位

### 岗位文件夹（100+）
- `能力要求.md` - 该岗位核心能力
- `公司投递.md` - 投递进度跟踪
- 其他专属资料

### 日常练习
- `练习-产品分析-xxx.md`
- `练习-费米估算-xxx.md`
- `练习-竞品分析-xxx.md`
