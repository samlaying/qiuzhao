


## 一、先厘清两个维度

| 维度          | 含义                | 用户心理    |
| ----------- | ----------------- | ------- |
| **好看**（吸引力） | 视觉愉悦、创意新颖、让人愿意看下去 | "我想看"   |
| **有用**（有效性） | 信息清晰、与我相关、能促成行动   | "对我有价值" |

> 真正优秀的广告不是二选一，而是让"好看"本身成为"有用"的一部分——**美感服务于信息传递，而非装饰。**



## 二、"好看"的特征

### 1. 视觉层面

- **高质感画面：** 高清素材、讲究的光影和色彩搭配，避免"廉价感"
- **统一的视觉风格：** 色调、字体、排版保持一致，形成品牌辨识度
- **留白与节奏感：** 不堆砌信息，给视觉呼吸的空间
- **动态设计精良：** 转场流畅、动效克制，不滥用特效

### 2. 创意层面

- **有故事感：** 哪怕只有 15 秒，也有起承转合（冲突 → 解决方案）
- **出人意料的开头：** 前 3 秒抓住注意力（悬念/反转/共鸣）
- **情感调动：** 幽默、温暖、惊喜、共鸣——让人有"情绪反应"
- **创意与产品强关联：** 不是为了炫技，创意本身就是产品卖点的表达

### 3. 审美层面

- **符合目标人群审美：** 面向年轻人可以大胆前卫，面向商务人群则需克制优雅
- **文化适配：** 色彩、符号、隐喻在目标文化中是正向的
- **"不尬"：** 避免过度滤镜、过度表演、过度包装带来的虚假感



## 三、"有用"的特征

### 1. 信息层面

- **卖点清晰：** 一条广告讲透一个核心价值点，不贪多
- **具体而非空泛：** "充电 5 分钟，通话 2 小时" 比 "超强续航" 有力得多
- - **精准触达：** 内容与用户的兴趣、场景、需求匹配
- **解决真实痛点：** 让用户感到"这说的就是我的问题"

### 2. 相关性层面（个性化）

- **精准触达：** 内容与用户的兴趣、场景、需求匹配
- **"这是为我推荐的"感知：** 用户感到被理解，而非被骚扰
- **时机恰当：** 在用户需要的时刻出现（如购物决策期、季节性需求期）

### 3. 行动层面

- **明确的行动指引（CTA）：** "立即购买""扫码领取""点击了解更多"
- **降低行动门槛：** 一键跳转、限时优惠、免费试用
- **信任背书：** 用户评价、权威认证、真实使用场景展示



## 四、"好看 + 有用"兼得的关键特征

将两个维度融合，真正优秀的广告通常具备以下 **六个核心特征**：

| 序号    | 特征         | 解释                   | 举例                    |
| ----- | ---------- | -------------------- | --------------------- |
| **1** | **钩子强**    | 前 3 秒内用视觉冲击或悬念抓住注意力  | Apple 广告开场的极致产品特写     |
| **2** | **故事化**    | 用叙事包装信息，而非硬塞卖点       | 讲一个用户从"痛点"到"解决"的小故事   |
| **3** | **个性化**    | 内容让目标受众感到"与我相关"      | AI 生成的个性化视频广告（正如此次研究） |
| **4** | **信息密度适中** | 传递足够有价值的信息，但不令人疲惫    | 一条视频只打一个核心记忆点         |
| **5** | **情感共鸣**   | 不仅告知，更能触动——让用户产生情绪连接 | 春节回家主题的情感广告           |
| **6** | **行动低门槛**  | 看完后知道下一步该做什么，且很容易做到  | 视频末尾一键跳转购买页           |


## 五、一个判断框架

可以用一个 **2×2 矩阵** 来理解：

```
              有用（高）
                │
    ┌───────────┼───────────┐
    │           │           │
    │  有效但    │  好看且有用  │
    │  乏味      │ ★ 最优区   │
    │  (能转化,   │  (既吸引,   │
    │  但没人想看) │  又转化)   │
不好├───────────┼───────────┤好
看  │           │           │看
    │  既不好看   │  好看但    │
    │  也无用    │  无用      │
    │  (完全失败) │  (叫好不叫座)│
    └───────────┼───────────┘
                │
              有用（低）
```

- **左上（有效但乏味）：** 硬广、弹窗广告——有信息但令人反感
- **右下（好看但无用）：** 创意短片很炫，但看完不知道卖什么
- **右上（好看且有用）：** **理想区间**——既让人愿意看，看完还会行动
- **左下（既不好看也无用）：** 低质量、无创意、无信息量的广告



## 六、结合本次研究的启示

回到生成式 AI 个性化视频广告的语境：

| 传统困境         | AI 的解法                          |
| ------------ | ------------------------------- |
| 好看但千篇一律 → 无效 | AI 为每个人生成**个性化内容**，提升相关性        |
| 有用但粗糙 → 没人看  | AI 保证**规模化产出**的同时维持**视觉质量**     |
| 好看又有用 → 成本太高 | AI 将成本降至 **1/10**，让"好看+有用"变得可负担 |

> **核心结论：** 好看是入口，有用是目的。最优秀的广告让用户**因为好看而停下，因为有用而行动**。生成式 AI 正在让这种"两全其美"从奢侈品变成标配。
