## 一、核心定义

面试中的"行业预估"不是背研报数据，而是考察：**给你一个不太熟悉的行业/市场，你能不能在几分钟内用逻辑框架估算出一个大致合理的数字？**

本质是**费米估算（Fermi Estimation）**——咨询公司 Case Interview 的核心能力。

---

## 二、四种常见题型

| 题型 | 示例 | 解题思路 |
|---|---|---|
| 市场规模估算 | "中国 AIGC 内容创作市场规模有多大？" | 供需两端拆解，用 TAM → SAM → SOM |
| 竞争格局判断 | "快手在短视频推荐市场大概占多少份额？" | 用户量/时长/收入三维度对比 |
| 趋势预判 | "未来 3 年 AIGC 生成内容渗透率会到多少？" | 历史增速 + 技术拐点 + 政策因素 |
| 机会评估 | "快手做 AIGC 视频生成能撬动多大增量？" | 增量用户 × 增量时长 × 变现效率 |

## 三、TAM-SAM-SOM 框架

```
TAM（Total Addressable Market）  整个市场的天花板
  ↓ × 可触达比例
SAM（Serviceable Available Market）  你能服务到的部分
  ↓ × 渗透率 × 转化效率
SOM（Serviceable Obtainable Market）  你实际能拿到的
```

### 实战：估算快手 AIGC 视频生成的可服务市场

**TAM**
```
中国短视频用户 ~10 亿
× 人均日消费时长 ~120 分钟
× 内容供给需求 → 约等于数千万条/日的内容需求
```

**SAM**
```
TAM × 快手市场份额（DAU 约 4 亿 / 短视频用户 10 亿 ≈ 40%）
× AIGC 技术可替代的内容比例（初始 ~5%，逐步提升）
```

**SOM**
```
SAM × 渗透率（第一年 ~10%）
× 转化效率（AIGC 内容的消费率 vs UGC，假设 70%）
```

> 关键：每一步都给出你的假设和逻辑，让面试官看到你的思考过程。

## 四、费米估算万能模板

### 模板结构

```
目标数字 = 人口基数 × 渗透率 × 使用频率 × 单次价值
```

### 示例：中国每天有多少杯咖啡被喝掉？

```
中国人口 14 亿
× 咖啡消费人群渗透率 ~15%（城市白领为主）= 2.1 亿人
× 人均消费频率（假设消费人群日均 0.5 杯）= 1.05 亿杯/日
```

验证：瑞幸 + 星巴克 + 其他品牌日销量加总，看量级是否吻合。

### 示例：快手每天有多少条短视频被上传？

```
快手 DAU ~4 亿
× 创作者占比 ~10% = 4000 万创作者
× 日均上传率（活跃创作者中）~30% = 1200 万活跃上传者
× 人均上传 ~2 条 = ~2400 万条/日
```

## 五、面试回答结构（结论先行）

讲师明确说：**"面试中需前置抛出关键结论与量化结果，再展开逻辑。"**

### 标准回答模板

```
"我估算 [目标数字] 大约是 [X]。

拆解逻辑是：
第一层：[基数] × [渗透率] = [中间值 A]
第二层：[A] × [频率] = [中间值 B]
第三层：[B] × [单次价值] = [最终结果]

我承认有几个假设可能偏差较大：
- [假设 1]：如果调整到 [Y]，结果是 [Z]
- [假设 2]：……

但量级上我认为是合理的，因为 [对比验证]。"
```

## 六、AIGC 赛道专项预估

### 必须提前研究的四个问题

1. **AIGC 内容渗透率**：短视频中 AIGC 内容目前占比？未来趋势？
2. **成本结构**：一条 AIGC 视频的 token 成本、推理时间、质量水平 vs 人工
3. **竞品动态**：抖音、B站、小红书在 AIGC 内容的策略
4. **商业化路径**：AIGC 内容如何影响广告效率、供给量、创作者生态

### 成本估算框架

```
AIGC 视频生成成本 = 文本生成成本 + 图片生成成本 + 视频合成成本

示例（15 秒短视频）：
- 文本脚本：GPT-4 级别 ~0.01 元
- 封面图：Stable Diffusion 级别 ~0.05 元
- 视频合成：~0.5-2 元（取决于模型和时长）
- 总计：~0.6-2.1 元/条

对比 PUGC：创作者时间成本 ~50-200 元/条（含拍摄+剪辑）
```

## 七、练习题

### 基础练习（每天 2 道，限时 5 分钟）

1. 北京地铁一天的客流量是多少？
2. 中国每年卖多少部手机？
3. 快手一天的广告收入大约是多少？
4. AIGC 生成一张图片的平均成本？

### 进阶练习（限时 10 分钟）

5. 估算中国 AIGC 内容创作市场的年规模
6. 如果快手把 AIGC 视频生成开放给所有创作者，一年后 AIGC 内容占比会到多少？
7. TikTok 在美国市场的广告收入大约是多少？

### 自验证练习

8. 已知快手 2024 年广告收入约 600 亿，反推验证这个数字是否合理（使用 [[12-数值预估能力]] 中的业务公式法）
