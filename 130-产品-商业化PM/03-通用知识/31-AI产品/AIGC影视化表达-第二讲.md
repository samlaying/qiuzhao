## 一、五种情绪流动模型（续·完整展开）

> 上一讲已介绍了五种模型的定义，本讲**逐一展示每个模型的实战视频片段与提示词写法**。

### 1.1 聚焦式（外→内收紧）

- **情绪流**：观众注意力从环境中一步一步被引导到主体核心，"像被一只无形的手抓住了脖子"
- **运动模式**：缓缓前推、放缓变焦、持续向主体逼近
- **适用场景**：悬念揭示前、情绪高潮前、品牌Slogan出现前
- **提示词示例**（老师现场展示）：描述了运动模式为"缓缓前推，放缓变焦，持续向主体逼近"，情绪流为"观众注意力从环境引导至主体核心"
- **注意**：老师特别提到这段视频的提示词中**没有放光圈参数**，原因是"教学嘛，让你们看得更清晰一些"

### 1.2 抽离式（内→外浮现）

- **情绪流**：从聚焦中向外浮现，命运感的浮现
- **场景特征**：镜头从主体向远处抽离，画面信息从局部扩展至整体
- **提示词**：老师在视频下方直接展示了对应的提示词文本

### 1.3 跟随式（共呼吸）

- **情绪流**：与主体共同呼吸，沉静跟随
- **运动特征**：镜头跟随主体同步移动

### 1.4 横扫式（横向铺陈信息）

- **情绪流**：信息的横向铺陈，交代场景，最终落到主角身上
- **案例解读**：主角正看向场外（窗外的小女孩），横扫镜头交代主角所处的场景环境
- **叙事逻辑**："接下来的镜头可能从小女孩出去了，也可能是他爸爸正在哪里叫他——我需要先把这个主角所在的场景环境交代清楚"
- **提示词**：同样在视频下方展示

### 1.5 爆发式（瞬间击穿）

- **情绪流**：节奏的瞬间击穿
- **运镜特征**：即推即拉、极速变焦、极速旋转
- **经典参考**：邵氏电影中常见的"突然从全景或中景推到大特写（眼睛上）"
- **案例解读**：男孩子处于静止状态→甩镜头转场→立马变成另一种心态/心境/状态
- **提示词**：老师在视频下方展示了完整的提示词

### 1.6 组合式（多模型融合）

- **特征**：15秒内完成一次情绪高低起伏的扇形曲线
- **案例拆解**：
  - 横移 + 跟随
  - 前推进入到女主眼睛→内心世界
- **提示词**：老师展示了组合运镜的完整提示词写法
- **核心观点**："这就是组合镜头的魅力"

### 1.7 扇形节奏曲线（完整模型）

> **一段完整的视频不是单一模型的应用，而是多个模型组合成一条节奏曲线。**

**标准曲线**：慢起 → 渐快 → 高潮 → 急停 → 余韵

- 这是**电影、广告、MV**常用的节奏架构
- 老师总结了5段式的对照工具表，建议截图保存

### 1.8 关于提示词的重要提醒

- 老师在**每个视频片段下方都写了对应的提示词**
- "你们是不是都没注意到？对每一个视频下面都有提示词啊，提示词我是怎么写的，你们可以仔细观察一下"
- 教学片段中刻意**没有放光圈参数**，是为了让观众更清晰地看到运镜效果本身



## 二、镜头组合与八大情绪配方

### 2.1 为什么需要学习镜头组合

> "一段AI视频如果每一帧都是美的，但镜头与镜头之间的衔接是生硬的，逻辑是跳跃的，情绪是断裂的——观众的反应一定是：**虽然好看，但不知道在讲什么东西**。"

老师观察到：很多AIGC玩家**不知道怎么组合镜头**，这个问题的根源在于**基础知识完全不了解**。

### 2.2 三大叙事逻辑

#### （1）平行剪辑
- **一句话总结**："两条线同时进行，互不交换"
- **情绪效果**：对比、并行、关系隐喻
- **经典AIGC应用**：
  - 男女同时起床准备约会（男的先起，女的又起）
  - 品牌产品在不同人手中使用的对比
- **口诀**：**"与此同时的……"**（与此同时发生了什么）

#### （2）交叉剪辑
- **一句话总结**："两条线交替推进，冲向中间这个交叉点"
- **情绪效果**：紧张、悬念、终极冲突
- **应用场景**：追凶、救援、品牌倒计时
- **口诀**：**"两边马上就要撞上了"**

#### （3）蒙太奇
- **一句话总结**："多个不连续的画面快速串联"
- **情绪效果**：时间压缩、情绪堆叠、概念表达
- **应用场景**：主角成长经历、品牌产品延伸过程、MV情绪段落
- **口诀**：**"让你瞬间明白这段时间发生了什么"**

#### 三大逻辑口诀汇总

| 逻辑 | 口诀 |
|------|------|
| 平行剪辑 | 与此同时的…… |
| 交叉剪辑 | 两边马上就要撞上了 |
| 蒙太奇 | 让你瞬间明白这段时间发生了什么 |

### 2.3 八大情绪配方

老师花了**非常长的时间**总结了一张完整的**情绪+镜头组合配方表格**，涵盖以下八种情绪：

| 情绪类型 | 说明 |
|---------|------|
| 暧昧 | 对应特定的镜头组合方式 |
| 史诗 | 对应特定的镜头组合方式 |
| 紧张 | 对应特定的镜头组合方式 |
| 忧郁 | 对应特定的镜头组合方式 |
| 暴躁 | 对应特定的镜头组合方式 |
| 绝望 | 对应特定的镜头组合方式 |
| （另外两种） | 表格中包含 |

## 三、剧作与叙事

### 3.1 核心观点

> **"好看的画面正在贬值，会讲故事的人在升值。"**

在AI画面普遍变好的时代，**唯一稀缺的能力就是会讲故事**。

老师提出的灵魂三问：
1. 这张画面**凭什么**让别人看完？
2. **凭什么**让别人转发？
3. **凭什么**让别人记住？

> "为什么有人用AI做的视频疯狂转发，但你做的视频朋友圈见底？说到底就是**叙事能力**。"

### 3.2 三幕式结构

| 幕 | 名称 | 内容 | 占比目标 | 情绪目标 |
|----|------|------|---------|---------|
| 第一幕 | **建立** | 他是谁？他在哪儿？发生了什么？ | 约25% | 让观众产生**关心** |
| 第二幕 | **对抗** | 主角遭遇阻碍并努力 | 约50% | 让观众**紧张** |
| 第三幕 | **解决** | 决战与回响 | 约25% | 让观众**释放** |

> 注：第二幕的标注中老师说"对不起打错字了"——PPT上"紧张"一词可能有排版问题，但含义是明确的。

#### 三幕式的压缩公式（按时长）

| 时长 | 建立 | 对抗 | 收束 |
|------|------|------|------|
| **15秒短片** | 3秒钩子 | 9秒展开 | 3秒落点 |
| **60秒短片** | 15秒建立 | 30秒对抗 | 15秒收束 |
| **3分钟品牌片** | 45秒痛点 | 90秒介入 | 40秒升华（+开头钩子） |

### 3.3 角色四处境（情绪四段式）

> 写剧本时**一定要注意**以下四个阶段：

| 阶段 | 内容 | 说明 |
|------|------|------|
| **处境** | 角色当前的状态 | 起点 |
| **渴望** | 追求/渴望什么 | 驱动力 |
| **障碍** | 遭遇什么阻碍 | 冲突核心 |
| **顿悟** | 获得什么领悟 | 转折点 |
| **转变** | 完成什么改变 | 终点 |

> 老师将**三幕式骨架**与**角色四处境**以及**情绪曲线**全部拉通，并配上了对应的组合镜头配方，形成了一套**可以直接抄作业的完整模板**。

### 3.4 剧作课后作业

> **题目**：30岁的都市女性，独立加班到深夜，接到了母亲的来电，决定连夜赶回家。
>
> **要求**：
> - 应用三段式的骨架
> - 填入角色的动机
> - 设计情绪曲线
> - 融合本课所学的所有内容（景别、景深、运镜、组合方式、三幕式、动机、情绪曲线）
> - 写出提示词并生成一段小片子
>
> **核心方法**："先填这张表，再去写提示词"

### 3.5 全课总结性方法论

> **"把这张表当作模板。下次接到任何AI视频的需求——或者自己要玩的需求（我们自己是自己的甲方）——先填这张表，再去写提示词。你不再是一个生成画面的人，你是一个设计故事的人。"**



## 四、AIGC剪辑与传统剪辑的核心区别

### 4.1 核心观点

> **"在AIGC的世界里，会捡废片的人才是一个好的剪辑师。"**

### 4.2 四大维度对比

| 维度 | 传统剪辑 | AIGC剪辑 |
|------|---------|---------|
| **素材来源** | 按计划拍摄（2:1到5:1的概率比） | 靠抽卡生成，存在不确定性 |
| **废片率** | 很低 | **极高** |
| **剧情与画面关系** | 剧本决定画面 | **画面可以反过来改剧情** |
| **核心能力** | 标准的控制 | **转化随机** |

> "剪辑不都一样吗？素材丢到剪辑软件里剪就完了吗？——区别非常大。"

### 4.3 废片二创法

#### 工作流程

1. **拿到抽卡素材后**，先不问"能不能用"，而是问"**有没有情绪**"
2. 在这个情绪之下，**15秒里能否截出1秒、3秒、5秒甚至10秒的有效片段**
3. 思考：通过**慢放、倒放、音画重构**等二创手段，能否赋予废片新生命？

#### 判断标准

> "一条素材来了之后，我们只需要判断这1~3秒之间有没有可用的地方。如果有，这条素材就可以留下来进行混剪或二创二次处理。"

#### 实战案例一：《绝尘》电吉他Solo段

- **创作构思**：这段音乐是电吉他Solo部分，想通过**车来模拟手在琴弦上弹Solo的状态**，前面超过的车辆和遮挡物类似琴弦
- **原始素材状态**：CS2.0之前的作品，素材废片率极高，前景护栏甚至都没有动
- **处理方式**：完全通过二创形式处理，从废片中提取可用片段
- **关键数据**：《绝尘》整部片子**50%–60%以上都是由废片组成**

#### 实战案例二：废片中截取1–2秒

- 原始素材**塑料感、AI感极强**
- 但其中有一小段（约1–2秒）**局部是可用的**
- 通过截取这1–2秒，配合音乐节奏和音效进行二创，赋予新生
- **判断原则**：不需要整条素材都好，只需要其中有1–3秒可用就值得保留

### 4.4 神片驱动法

#### 核心理念

> "当AI给了你一个意外的强画面时，**千万不要删掉**，即使它和你的剧本有些出入——让剧情为它让路。"

#### 操作步骤

1. 先确定这个画面放在哪里（开头、中间、高潮还是结尾）
2. 再反推前后结构
3. 甚至可以**改剧情**来适配这个意外好画面

#### 实战案例：《绝尘》中角色"剁脚"动作

- **原始提示词中并没有**让角色做"剁脚/踩地"的动作
- AI抽卡时意外生成了角色**俏皮地跺了一下脚**的效果
- 老师觉得这个画面**很俏皮，凸显了角色性格**
- **处理方式**：
  - 保留这条素材
  - **专门让配音演员根据这个动作写了一句台词**："闭嘴"
  - 原本剧情里没有这一段，为了这个意外好画面**做了微型剧情调整**

#### 对导演的要求

> "这对导演的要求是极高的。传统剪辑是控制素材，AIGC剪辑是**顺应素材**。"

### 4.5 AIGC剪辑五步工作流

| 步骤 | 操作 |
|------|------|
| **1. 分类** | 将素材分为三类：**好素材、废片、神片段** |
| **2. 筛选** | 如果三类都不符合→彻底废素材（当花絮或删除） |
| **3. 锁定** | 先锁定**抽卡中最强的画面** |
| **4. 反推** | 围绕这个最强画面**反推前后结构** |
| **5. 二创** | 用**音乐节奏**和**音效**让素材成立，完成二次创作 |

> **核心定义**："AIGC的剪辑不是整理素材，而是**从随机里面重新发明新的故事**。"



## 五、转场的本质

### 5.1 核心观点

> **"转场不是简单的叠加特效，它是叙事的缝合点（缝儿）。"**

#### 两种转场思维

| 类型       | 炫技型    | 叙事型     |
| -------- | ------ | ------- |
| **目的**   | 展示转场效果 | 服务于情绪衔接 |
| **观众反应** | 出戏     | 沉浸，不跳戏  |

> **"好的转场，观众是注意不到的。坏的转场，观众只会看到特效，却忘了故事。"**

### 5.2 新手常见问题

- 很多人**沉溺于用黑屏进行场景衔接**
- 大量使用黑场和叠化做衔接
- **本质原因**：**"你自己对画面不够自信，不知道如何去衔接两个场景之间的关系，所以用了一个黑场"**

### 5.3 《绝尘》转场实战案例

#### 案例一：设计型转场

- 女主要进入房间
- 设计了一个特定的视觉元素进行转场衔接（非简单黑屏）

#### 案例二：颜色匹配转场（黑转黑）

- 场景需要从室内转到室外
- **如果正常处理**：大多数人会用黑屏转场
- **老师的处理**：利用车盖内部的黑色空间，将摄像头放入车盖中，然后打开车盖——用**车盖内部的黑色**自然过渡到下一个场景
- **技术本质**：这是**颜色匹配转场**——黑转黑，利用画面中天然存在的黑色元素做自然衔接

#### 案例三：分屏+眼神匹配转场

- 角色在工作室改装车辆→转到比赛现场
- **设计方式**：
  - 采用**漫画分屏**形式
  - 保留角色的**眼神方向**作为视觉线索
  - 将三个角度同时呈现在**三屏分屏**中
  - 三辆车同时停下来，自然过渡到比赛现场
- **效果**：无缝衔接比赛前的状态，直接进入比赛现场
- **核心**：没有用黑屏或叠化，而是通过分屏设计+视觉匹配实现转场

### 5.4 五种基础转场详解

#### （1）硬切

- **定义**：场景之间直接切换，不加任何转场特效
- **案例**：老师展示了从一个场景直接硬切到下一个场景的实例
- **强调**："我没有加任何的转场特效，只是硬切"
- **适用**：当两个场景之间的情绪和逻辑足够紧密时，硬切反而最有力

#### （2）叠化

- **定义**：画面渐变过渡
- **说明**：剪辑软件中有多种叠化形式可选
- **老师的使用态度**：可以成立，也很好看，但属于"导演自己的选择"——看个人需要怎样的转场形式
- **注意**：不要滥用叠化来掩盖不知道如何衔接的问题

#### （3）匹配剪辑

三种匹配方式：

| 匹配类型 | 说明 | 案例 |
|---------|------|------|
| **颜色匹配** | 利用画面中相似的颜色衔接 | 车盖黑色→下一场景的黑屏过渡 |
| **动作匹配** | 利用相似的动作衔接 | 上一个场景的动作在下一个场景中延续 |
| **形状匹配** | 利用相似的形状/构图衔接 | 画面中圆形物体→切到下一个场景中的圆形元素 |

#### （4）遮罩转场
- 利用画面中的遮挡物（如经过镜头前的物体）自然过渡到下一场景

#### （5）分屏转场
- 画面分割为多个区域，同时展示不同角度或时间线
- 案例中使用了**三屏分屏**展示三个角色/角度



## 六、声音的设计

> **"声音是需要去设计的，就跟你的剪辑画面一样重要。"**

### 6.1 核心理念

- 声音不是事后补配的附属品，而是**与画面同等重要的创作维度**
- 声音设计应该**前置**，在策划阶段就纳入考虑

### 6.2 声音在二创中的关键作用

- 在废片二创中，**音乐节奏和音效是让素材"成立"的关键**
- AIGC剪辑五步工作流的最后一步：**用音乐节奏和音效让素材成立**
- 《绝尘》电吉他Solo案例中，正是通过音乐节奏赋予了废片全新的叙事生命

### 6.3 配音与剧情联动

- 神片驱动法案例中，为了让意外好画面融入剧情，**专门让配音演员根据画面动作写台词**
- 说明声音（包括对白）可以是**为了适配画面而反向设计**的

## 九、贯穿两讲的核心方法论总结

### 9.1 身份升级路径

| 阶段 | 身份 | 核心能力 |
|------|------|---------|
| 入门 | 抽卡生成者 | 碰运气等好结果 |
| 进阶 | 画面决策者 | 知道用什么镜头、景深、运镜 |
| 高阶 | 故事设计师 | 理解叙事结构、情绪节奏、镜头语法、声音设计 |

### 9.2 创作工作流（完整）

```
第一步：构思故事 → 填写三幕式表格 + 角色四处境 + 情绪曲线
第二步：选择镜头 → 根据情绪密码选择焦段、景别、运镜
第三步：生成素材 → 写提示词（含焦段、光圈、景深、运镜描述）
第四步：素材分类 → 好素材 / 废片 / 神片段
第五步：锁定最强画面 → 围绕它反推结构调整
第六步：二创处理 → 慢放/倒放/音画重构，截取1-3秒有效片段
第七步：组合剪辑 → 三大叙事逻辑 + 情绪配方 + 五种基础转场
第八步：声音设计 → 音乐节奏 + 音效 + 对白，与画面同等重要
第九步：风格收束 → 混音三条铁律，确保全片风格统一
```

### 9.3 老师的终极告诫

> **"切记，学AIGC不是学怎么召唤画面——所谓的抽卡——而是学怎么决策画面。我们要有决策权。"**

> **"你不再是一个生成画面的人，你是一个设计故事的人。"**
