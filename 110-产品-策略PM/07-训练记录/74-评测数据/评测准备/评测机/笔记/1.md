## 二、方法论：做题三步骤

### 步骤一：把握话题

**为什么需要把握话题？**

1. 国考题越来越需要从**整体**去把握
2. 这不是故意反套路，而是**语言表达本身的特点**决定的
3. 国考选取的文章一般比较规范，规律和特点更明显
4. 逻辑填空的文段通常只有 3~4 行，摘自原文同一段话
5. 如此短的一段话，**必然围绕某个特定话题**展开
6. 前后文段具有**系统性和连续性**，用词不应偏离话题太远
7. 不同句子功能和表达不同，因此具体词语会有不同用法和搭配，但话题一致

**实战示例：音乐×电影题**

- **第一句**：音乐文化对不同文化背景下的人们能形成有效传播
- **第二句**：转到电影，要发挥音乐的作用
- **话题归纳**：发挥音乐在电影中的**文化传播作用**
- **第二空选"共鸣"**：能体现音乐在文化与观众之间的作用
- **排除"互动"**：音乐文化传播是**单向性**的，互动需要观众反馈回来，且"互动"与音乐相关性不强

### 步骤二：寻找命题线索

**什么是线索？**

> 国考大纲："根据材料查找**主要信息**及**重要细节**"——这两个东西就是线索。

#### 主要信息

- 指句子或空格所要表达的**逻辑层面的含义**
- 通常出现在**紧挨空格的前或后**（语言表达的特点：相关联内容放在一起）
- 关注**逻辑关联词**——可能使逻辑提示点距离更远
- 不能忽略**整体话题/主旨**（也是主要信息的一部分）

#### 重要细节

- 从**语法**角度理解：主谓宾定状补的搭配问题
- **并列词性一致**：不能一个动词一个名词
- 大部分情况用不上语法，不必单独抠语法细节
- 各线索不必严格区分，**最终是综合考虑**

#### 进阶技巧：预判

- 找到线索、确定逻辑含义后，**不看选项**预判可能填什么词
- 好处：锻炼写作用词能力 + 做题更快
- **前提**：要足够熟练
- 不够熟练时**不能太绝对**，要时常质疑自己的判断

#### 为什么有时找不到/找错线索？

| 原因 | 说明 |
|------|------|
| 不够熟练 | 基本功不足 |
| 陷入机械思维 | 只按固定套路找，没有从语言角度真正理解 |
| 只看局部，以偏概全 | 没有把握整体话题 |
| 确实没线索 | 个别题线索不足，需靠词语辨析 |

**线索例题解析：**

**【例1】载人航天系统（科技密集）**
- 话题：载人航天系统**集中了**众多科技要素
- 三个空线索都不够强，只能看选项是否符合话题
- 第一空：排除"科技广泛"（搭配错误，应为"科技的广泛运用"）；排除"尖端/先进"（偏离"集中"的话题）→ **"密集"** 符合话题且搭配正确
- 第三空："当之无愧"形容集大成者，带双引号像名号 → 搭配合适
- **选B**

**【例2】底线思维（风险控制）**
- 话题：风险控制要坚持底线思维
- 线索：祸患刚形成就要杜绝 + 抓早抓小 + 避免重大风险
- **预判**：防微杜渐式（刚出现微小苗头就预防）
- 选**C.见微知著**（看到微小→知道发展趋势）
- **排除B.审时度势**：机械对应"早""小"，与底线思维、杜渐萌绝其根、避免风险均无关

**【例3】战场态势（洞若观火）**
- 话题：战场上应当正确识势
- 线索："力求"是目的引导词→找方式；观察态势→**看**得清楚明白
- 选**A.洞若观火**（看得清楚明白）
- 排除"胸有成竹"：①字面上无"清楚明白"；②义为有把握，后文已有"把握中心"，不能先把握再把握；③"胸有成竹"是对**自己的**把握，非对他物

**【例4】年轻干部抓落实（副省题）**
- 话题：年轻干部要提高抓落实能力
- **第一空**：弱并列（脚踏实地 + 以上率下），无法确定是填与"以上率下"并列还是围绕"脚踏实地"→ 先放
- **第二空**：亲自做 vs 只挂帅不出征（表面功夫/虚的）→ 填"不实际做"的词
- **第三空**：对应"抓铁有痕、踏石留印、钉钉子" → 踏实
- 第二空"凌空蹈虚"（只干虚的）✓，"好高骛远"与挂帅出征无关 ✗，"刚愎自用"（固执）✗
- **锁定B**（一马当先→ 起表率/引领作用；凌空蹈虚；稳扎稳打）

### 步骤三：准确辨析词语

#### 三个层次（由浅入深）

| 层次 | 内容 | 适用场景 |
|------|------|----------|
| **①了解大体含义** | 大部分题目够用 | 所有考试 |
| **②掌握准确定义** | 借助字面理解 + 语法用法 | 难题、深圳市考等 |
| **③辨析多词区别** | 近义词的细微差异 | 选项中出现近义词时 |

#### ① 了解大体含义

- 重点关注**容易望文生义**的词：
  - 惨淡经营（不是"很惨"）
  - 首当其冲、首鼠两端、不赞一词、目无全牛、差强人意
  - 浮光掠影（不是"描写景色"）
- 关注**成对易混词**：
  - 不以为然 ≠ 不以为意
  - 不负众望 ≠ 不孚众望

#### ② 掌握准确定义（以"浮光掠影"为例）

- **浮光**：水面的反光；**掠影**：掠过的影子
- 都是一闪而过、一晃消逝的事物
- 准确定义：比喻**印象或观察不深刻**（侧重**印象浅**）

> **积累渠道**：官媒文章（光明网、人民网、人民日报等）。但注意人民网/光明网会**转载**不一定规范的来源文章，不要看到他们用了就认为一定正确。

#### ③ 辨析近义词（以"浮光掠影" vs "走马观花"为例）

| 词语 | 侧重逻辑 | 适用场景 |
|------|----------|----------|
| **浮光掠影** | 印象浅（一闪而过） | "一瞥所见"，无速度快的含义 |
| **走马观花** | 看得太快（骑马看花，速度快） | "到此一游"式，快速浏览 |

**实战辨析：**
- 例一："一瞥所见，尚有许多应用正在被推广" → 无"快"→ **浮光掠影** ✓
- 例二："到此一游式"旅游 → 侧重快速 → **走马观花** ✓

## 三、真题复盘：去年国考执法卷逻辑填空

### 第21题：公交专用车道开放共享

- **话题**：公交车道共享，既不能影响公交效率，也要方便车辆通行
- **线索**：空格应与整体逻辑相反（既要也要的反面 = 只顾及一个方面）
- **选B.顾此失彼**（"顾"字直接对应"只顾一个方面"）
- 排除"厚此薄彼"：侧重不公平对待
- **做题策略**：已确定选项后不纠结，类似加强削弱题——有完美对应的直接选，不要过多分析

### 第22题：环境影响评价

- **话题**：环境影响评价的概念 + 作用
- **线索**：与"第一道防线"并列 + 搭配"控制环境风险的___"（定语+宾语）
- **预判**：防线类逻辑 → 选**A.安全阀**
- 排除"预警机"：①与防线无关；②预警只是预测/警示，不是控制风险；③不要强行对应前面定义中的"预防"

### 第23题：空间碎片清除技术

- **话题**：两类方案目的相同
- **预判**：不同方式，相同目的 → **殊途同归** ✓
- 选**C**，无需过多分析

### 第24题：鼓励担当作为（较难）

- **话题**：通过方法鼓励担当作为
- **隐藏主体**：管理者（不是党员自身）——鼓励、管死、明方向/正风气/强免疫都是管理者角度
- **第一空**：管死了→不敢做（结果对应"暮气沉沉、一潭死水"）
- **第二空**：不应从党员角度选"守底线"（应从管理者角度）
- 注意并列时**性质一致**

### 第25题：公正司法

- **话题**：公正司法的意义与实践
- **第一空**：对应"最后一道防线" → **终局性** ✓
- **第二空**：对应"零距离"（可见可感+贴近+不等于初级信任）→ **A选项**

### 第26题：破冰船

- **第一空预判**：面对坚冰无能为力 → **望而却步** ✓
- **第二空**：力量最强+开路先锋→轻松破冰 → **轻而易举** ✓
- **选B**

### 第27题：信息保护与利用共赢

- **话题**：信息保护和利用应实现共赢
- **两空逻辑**：都是"分开/分离"
  - 第一空：共赢的反面→分开
  - 第二空：个人信息包含敏感信息→要**剥离开**
- "区别"只是识别不同 ✗；"A和B独立开来"搭配错误（应为"把A从B中独立出来"）
- **选D.隔绝/剥离**（"剥离"用得好：包容关系中剥掉一小片敏感信息）

### 第28题：木刻分水

- **话题**：按面积确定水量
- **第一空**：核心思想→根据面积确定水量→很**公平**
- **选A.公平/精打细算**
- 排除"科学"：太泛化，应围绕具体做法的核心思想选

### 第29题：浅与显

- **话题**：围绕"浅"和"显"展开
- **两空对应同一逻辑**：应填"显"（明显/突出）
- **选C.显山露水/一目了然**（都是清楚明显的意思）
- 确定后不再管其他选项

### 第30题：确保史书真实性

- **第一空**：因随意取舍/记忆有误/心存故意→**同时搭配三个原因**
  - "虚构/掩盖"只对应故意 ✗
  - **"偏离"**能同时搭配三个 ✓
- **第二空**：搭配"可能性"→提高/降低
  - 重复检验不可能完全绝对→**降低** ✓（不能用"消除"）

### 第31题：农村发展两种错误倾向

- **第一空**：与"平均用力"并列，后有解释说明（套用所有农村）
- **第二空**：尊重农村发展实际和规律 → **因地制宜** ✓
- 类似表达"脚踏实地/步步为营/坚定不移"与尊重实际无关，仅为通顺

### 第32题：中国化落地

- **第一空**：中国化结果，与"深入人心"并列 → **落地生根**（本土化结果+扎根与深入微妙相关）
- **第二空**：与实际出发相反+脱离国情+主观想象 → **异想天开** ✓
  - 同时符合：不从实际出发 + 脱离国情 + 主观想象 + 乱想

### 第33题：区块链物流

- **话题**：区块链让商品有"身份证"→消费者更放心
- **选独一无二+不可篡改**，简单直接

### 第34题：调研流于形式（较难）

- **第一空**：孤立的盆景→以偏概全
- **第二空**：对新情况多凭主观判断下结论→**缺乏客观→针对性不强**
  - 排除"时效性"：与缺乏客观判断无关
  - 不要被"刻舟求剑"迷惑，题目已给出完整解释→**优先看离空格更近的解释说明**

### 第35题：守正与创新

- **第一空**：错误的"守正"（守旧的东西）+ 与"循规蹈矩"并列
- **第二空**：错误创新+与"凭空幻想"并列+不尊重规律 → **恣意妄为**（乱想+乱来并列 ✓）
- **第三空**：表面是"方式→目的"，实际是**解释说明**（创新≈推陈出新，守正≈恪守正道）
  - 回看前文→守住本和源/根和魂 → **固本强基** ✓
  - 排除"返璞归真"（回到最质朴状态≠守正）
  - 排除"脱胎换骨"（专有术语，不会作为逻辑填空正确选项）

### 第36题：读书需要思考（较难/有争议）

- **第一空**：比阅读更进阶 → 升华/深化 ✓
- **第二空**：与机械/被动并列→缺乏思考 → 简单/肤浅
- **第三空**：走马观花强调"快速"，此处无"快"的语境 → 不够好
  - "人云亦云"：作者怎么写我就怎么读→也可解释通
  - 此题有争议，**考场上若纠结，参考大多数人选择**

### 第37题：量子理论结合

- **第一空**：难以判断（著名/奇特/神秘/大胆都说得通）
- **第二空最明确**：转折→结合方式不是非常好 → **不直观/不合理/不简便**
- **选C**
- 第三空：寻找理论是"目标" ✓

### 第38题：防沉迷机制

- **第一空**：管控不严格→排除"干扰"（不是干扰）
- **第二空**：清理系统→排除"彻底"（太绝对）；排除"严厉"（无关）
- **第三空**：与"诚心正义"转折→**虚与委蛇**（虚情假意/敷衍应对）✓
  - "虚张声势"与诚心正义构不成转折

### 第39题：AI绘画局限性

- **第一空**：限定条件→排除"本质"（本质不应随条件变化）；排除"前提"
- **第二空**：同时搭配构图/配色/细节
  - "精致"✓；"高妙"能搭配但与句意不符；"妥帖"细节无法与某物贴合；"丰富"构图不能搭配
- **第三空**：AI创作 vs 传统理念→只是理念**不同/有区别**，不是"背道而驰"（错误做法违背初衷），不是"相容"要求
- **选B**

### 第40题：调查研究思路

- **第一空**：导致千头万绪→A/B/D都可以，排除"任重道远"
- **第二空**：排除"高屋建瓴"（无"站位高"语境）
  - "追根溯源"≈直面真问题本身，等于与后文重复
  - "抽丝剥茧"：一层层剥开→看到最底层真问题 → **形象更搭** ✓
  - 语法上此空应为**状语**（怎么去直面真问题），追根溯源更像并列
- **第三空**：看到真问题后→解决问题（不是再看一遍问题）
  - 此处命题人**漏了一个步骤**（先明确问题→再解决），导致感觉脱离话题

## 四、核心做题策略总结

| 策略 | 说明 |
|------|------|
| **先把握话题** | 略读全文，归纳核心话题/主旨 |
| **找线索** | 主要信息（逻辑含义）+ 重要细节（语法搭配），紧挨空格的前后优先 |
| **预判** | 确定逻辑后先不看选项，预判可能的词（需足够熟练） |
| **完美匹配即选** | 有词完全符合预判逻辑→直接选，不要多想 |
| **不要机械对应** | 看到某词就强行对应→容易选错，要综合所有线索 |
| **并列同时搭配** | 填的词必须能与所有并列项同时搭配 |
| **解释说明优先** | 有完整解释句子时，优先看解释而非自行推理 |
| **避免太绝对** | 一般不优先选过于绝对的词语 |
| **考场策略** | 纠结时参考大多数人选择；竞争性考试不必每题都对 |
